# Домашнее задание — Урок 13

**Задание:** «Анимированная карточка»  
**Время:** ~30–45 минут  
**Файлы:** `animated-card.html`, `css/card.css` (можно в той же папке, что практика на уроке)

---

## Описание

Создай карточку товара или услуги с **анимацией при наведении** (`:hover`). Карточка должна реагировать на курсор плавно и выглядеть аккуратно.

---

## Требования

1. **Структура карточки:**
   - Изображение (или цветной блок-заглушка)
   - Заголовок `<h3>`
   - Краткое описание `<p>`
   - Кнопка «Подробнее»

2. **Анимация при hover на всю карточку:**
   - Лёгкое увеличение (`transform: scale`)
   - Тень становится заметнее (`box-shadow`)
   - Переходы через `transition` (не менее 2 свойств)

3. **Дополнительный эффект на кнопке:**
   - При hover на кнопку — смена цвета фона с `transition`

4. **Бонус-анимация (опционально):**
   - Badge «Хит» или «-20%» с пульсацией через `@keyframes`

5. **Доступность:**
   - Добавь блок `@media (prefers-reduced-motion: reduce)` с отключением анимаций

---

## Пример структуры

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Анимированная карточка</title>
    <link rel="stylesheet" href="css/card.css" />
  </head>
  <body>
    <article class="card">
      <span class="card__badge">Хит</span>
      <div class="card__image"></div>
      <div class="card__body">
        <h3 class="card__title">Название товара</h3>
        <p class="card__text">Краткое описание товара или услуги.</p>
        <button class="card__btn" type="button">Подробнее</button>
      </div>
    </article>
  </body>
</html>
```

```css
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
  transform: scale(1.03);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}
```

## Критерии оценки

| Критерий | Балл |
| -------- | ---- |
| Карточка содержит изображение, заголовок, текст и кнопку | обязательно |
| Hover на карточку с `transition` (минимум 2 свойства) | обязательно |
| Использован `transform` (не width/height) | обязательно |
| Кнопка с отдельным hover-эффектом | обязательно |
| Анимации плавные (150–400 мс) | обязательно |
| Есть `prefers-reduced-motion` | желательно |
| Badge с `@keyframes` пульсацией | бонус |

---

## Бонус (по желанию)

1. **Сетка карточек** — 3 карточки в ряд (flex или grid), каждая с hover
2. **Задержка по очереди** — `transition-delay` разный для каждой карточки при hover на контейнер
3. **Появление при загрузке** — `@keyframes fadeInUp` для карточки

## Частые ошибки — проверь себя

- [ ] `transition` задан на `.card`, а не только на `.card:hover`
- [ ] Длительность анимации не слишком долгая (не 2+ секунды для hover)
- [ ] Используется `transform`, а не изменение `width`/`height`
- [ ] Имя в `@keyframes` совпадает с `animation-name`
- [ ] Кнопка имеет `cursor: pointer`
