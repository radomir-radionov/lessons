## Цели урока

К концу занятия ученик сможет:

1. Создавать плавные переходы с помощью `transition` при изменении состояния (например, `:hover`)
2. Комбинировать `transform` и `transition` для движения и масштабирования элементов
3. Описывать цикличные анимации через `@keyframes` и свойства `animation-*`
4. Применять анимации осмысленно — без перегруза интерфейса

**Результат:** ученик добавляет на страницу кнопку с hover-переходом, пульсирующий badge и выезжающее меню.

## Краткое содержание блоков

### Блок 1 — Введение (0–5 мин)

- Анимации улучшают UX: обратная связь, фокус внимания
- `transition` — от точки А к точке Б; `@keyframes` — сложный цикл
- Не злоупотреблять: длительность 150–400 мс для UI

### Блок 2 — transition (5–15 мин)

- `transition-property`, `duration`, `timing-function`, `delay`
- Сокращение: `transition: property duration timing-function delay`
- Триггеры: `:hover`, `:focus`, изменение класса

### Блок 3 — transform + transition (15–25 мин)

- `transform: scale()`, `translate()`, `rotate()`
- `transform-origin`, плавное изменение при hover
- Почему `transform` лучше `width`/`left` для анимаций

### Блок 4 — @keyframes (25–35 мин)

- Синтаксис `@keyframes name { 0% {} 100% {} }`
- `animation-name`, `duration`, `iteration-count`, `direction`
- Пример: пульсирующий badge

- Минимум: задачи 1–3; задачи 4–5 — для быстрых учеников

## Частые проблемы

| Проблема                              | Решение                                                              |
| ------------------------------------- | -------------------------------------------------------------------- |
| Анимация не запускается               | Проверить имя в `animation-name` и `@keyframes` — должны совпадать   |
| Рывки при hover                       | Добавить `transition` на базовое состояние, не только на `:hover`    |
| Элемент «прыгает» при scale           | Использовать `transform-origin: center` или задать фиксированные размеры |
| transition не срабатывает             | Убедиться, что свойство анимируемое (не `display`, не `auto`)        |
| Анимация зацикливается бесконечно     | Проверить `animation-iteration-count` (по умолчанию `1`)             |

## Что НЕ входит в урок 13

- JavaScript-анимации и библиотеки (GSAP, Framer Motion) — за рамками модуля
- SVG-анимации и Lottie — не в этом курсе
- CSS Scroll-driven animations — экспериментальные возможности
- 3D-трансформации (`perspective`, `rotate3d`) — только упоминание
