# Практические задачи — Урок 1

**Время на занятии:** 32–55 мин (~23 минуты)  
**Файл:** все задачи выполняются в одном файле `index.html`  
**Порядок:** задачи идут по нарастающей сложности — каждая следующая дополняет предыдущую

---

## Задача 1 — «Первая страница» (5 мин)

### Задание

Создай файл `index.html` с полным каркасом HTML-документа:

1. Добавь `DOCTYPE`, `html`, `head`, `body`
2. В `<title>` напиши своё имя
3. В `<body>` напиши текст «Привет, мир!»
4. Открой файл в браузере и убедись, что страница отображается

### Критерии выполнения

- [ ] Файл называется `index.html`
- [ ] Есть `<!DOCTYPE html>`
- [ ] Есть теги `<html>`, `<head>`, `<body>`
- [ ] В `<title>` указано имя ученика
- [ ] На странице виден текст «Привет, мир!»
- [ ] Страница открывается в браузере без ошибок

### Подсказка

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <title>Твоё имя</title>
  </head>
  <body>
    Привет, мир!
  </body>
</html>
```

## Задача 2 — «О себе» (8 мин)

### Задание

Дополни страницу информацией о себе:

1. Замени «Привет, мир!» на заголовок `<h1>` с твоим именем
2. Добавь 2 абзаца `<p>`:
   - Первый — о своём городе
   - Второй — о своих хобби
3. В тексте используй `<strong>` (важное слово) и `<em>` (акцент)

### Критерии выполнения

- [ ] Есть заголовок `<h1>` с именем
- [ ] Есть 2 абзаца `<p>` с разным содержанием
- [ ] Использован тег `<strong>` хотя бы один раз
- [ ] Использован тег `<em>` хотя бы один раз

### Подсказка

```html
<h1>Алексей</h1>
<p>Я живу в <strong>Минске</strong>.</p>
<p>Моё любимое хобби — <em>программирование</em>.</p>
```

## Задача 3 — «Ссылки» (5 мин)

### Задание

Добавь на страницу две ссылки:

1. Ссылка на твой любимый сайт (открывается в той же вкладке)
2. Ссылка на YouTube или другой сайт (открывается в **новой вкладке**)

### Критерии выполнения

- [ ] Есть минимум 2 ссылки с тегом `<a>`
- [ ] У каждой ссылки указан атрибут `href` с рабочим URL
- [ ] Одна ссылка использует `target="_blank"`
- [ ] Ссылки кликабельны и ведут на нужные сайты

### Подсказка

```html
<p>Мой любимый сайт: <a href="https://google.com">Google</a></p>
<p>Смотрю видео на <a href="https://youtube.com" target="_blank">YouTube</a></p>
```

## Задача 4 — «Списки» (5 мин)

### Задание

Добавь на страницу два списка:

1. **Маркированный список** (`<ul>`) из 3 пунктов — твои любимые фильмы, игры или книги
2. **Нумерованный список** (`<ol>`) из 3 шагов — например, как приготовить чай или кофе

### Критерии выполнения

- [ ] Есть маркированный список `<ul>` с 3 пунктами `<li>`
- [ ] Есть нумерованный список `<ol>` с 3 пунктами `<li>`
- [ ] Перед каждым списком есть заголовок или описание (текст или `<p>`)

### Подсказка

```html
<p>Мои любимые игры:</p>
<ul>
  <li>Minecraft</li>
  <li>CS2</li>
  <li>Dota 2</li>
</ul>

<p>Как приготовить чай:</p>
<ol>
  <li>Вскипятить воду</li>
  <li>Положить чайный пакетик в чашку</li>
  <li>Залить кипятком и подождать 3 минуты</li>
</ol>
```

## Задача 5 — «Изображение» (5 мин)

### Задание

Добавь на страницу изображение:

1. Используй тег `<img>`
2. Укажи атрибут `src` — можно скачать картинку в папку проекта или использовать URL из интернета
3. Обязательно укажи атрибут `alt` с описанием картинки
4. Добавь горизонтальную линию `<hr>` перед или после изображения

### Критерии выполнения

- [ ] На странице есть тег `<img>`
- [ ] Указан атрибут `src` (изображение отображается)
- [ ] Указан атрибут `alt` с осмысленным описанием
- [ ] Есть тег `<hr>` на странице

### Подсказка

**Вариант 1 — картинка из интернета:**

```html
<hr />
<img src="https://placehold.co/200x200" alt="Моё фото-заглушка" />
```

**Вариант 2 — локальный файл:**

1. Скачай картинку в папку `my-first-site/images/`
2. Укажи путь:

```html
<img src="images/photo.jpg" alt="Моё фото" />
```
