**Задание:** «Моя визитка»  
**Время:** ~30–45 минут  
**Файл:** `index.html` (можно создать новую папку `my-card`)

## Описание

Создай одностраничный сайт-визитку о себе. Это твоя первая самостоятельная работа — используй всё, что мы изучили на уроке.

---

## Требования

Страница должна содержать:

1. **Заголовок вкладки** (`<title>`) — «Визитка [Твоё имя]»
2. **Главный заголовок** `<h1>` — твоё имя и фамилия (с атрибутом `id`)
3. **Секция «Обо мне»**
   - Подзаголовок `<h2>` — «Обо мне»
   - Абзац `<p>` с описанием (минимум 3 предложения, атрибут `class`)
   - Используй `<strong>` и `<em>` в тексте
4. **Секция «Мои навыки»**
   - Подзаголовок `<h2>` — «Мои навыки»
   - Маркированный список `<ul>` из 5 навыков или интересов
5. **Секция «Контакты»**
   - Подзаголовок `<h2>` — «Контакты»
   - Нумерованный список `<ol>` с тремя пунктами-ссылками:
     - Email
     - Социальная сеть (VK, Telegram, Instagram и т.д.)
     - Мессенджер или другой контакт
6. **Фото** — изображение через `<img>` с обязательным атрибутом `alt`
7. **Разделители** — горизонтальные линии `<hr>` между секциями
8. **Комментарии** — добавь HTML-комментарии `<!-- -->` перед каждой секцией

---

## Пример структуры

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Визитка Алексей Петров</title>
  </head>
  <body>
    <!-- Шапка -->
    <h1 id="main-title">Алексей Петров</h1>
    <img src="https://placehold.co/150x150" alt="Фото Алексея Петрова" />

    <hr />

    <!-- Секция: Обо мне -->
    <h2>Обо мне</h2>
    <p class="about-text">
      Мне <strong>16 лет</strong>, я учусь в школе и увлекаюсь
      <em>программированием</em>. Живу в Минске. Мечтаю стать веб-разработчиком
      и создавать полезные сайты.
    </p>

    <hr />

    <!-- Секция: Навыки -->
    <h2>Мои навыки</h2>
    <ul>
      <li>HTML</li>
      <li>Работа с компьютером</li>
      <li>Английский язык</li>
      <li>Командная работа</li>
      <li>Быстрое обучение</li>
    </ul>

    <hr />

    <!-- Секция: Контакты -->
    <h2>Контакты</h2>
    <ol>
      <li><a href="mailto:alex@example.com">alex@example.com</a></li>
      <li><a href="https://vk.com/username" target="_blank">ВКонтакте</a></li>
      <li><a href="https://t.me/username" target="_blank">Telegram</a></li>
    </ol>
  </body>
</html>
```

---

## Критерии оценки

| Критерий                                                    | Балл        |
| ----------------------------------------------------------- | ----------- |
| Валидная структура HTML (`DOCTYPE`, `html`, `head`, `body`) | обязательно |
| Минимум 8 разных HTML-тегов                                 | обязательно |
| Все ссылки рабочие (кликабельны)                            | обязательно |
| У всех изображений есть `alt`                               | обязательно |
| Использованы `id` и `class`                                 | обязательно |
| Есть комментарии к секциям                                  | обязательно |
| Код читаемый (отступы, пустые строки между секциями)        | обязательно |

## Бонус (по желанию)

Выполни дополнительные пункты для углубления знаний:

1. **Ссылка «Наверх»** — внизу страницы добавь ссылку `<a href="#main-title">Наверх</a>`, которая прокручивает к заголовку
2. **Вторая страница** — создай файл `about.html` с дополнительной информацией и ссылками между `index.html` и `about.html`:
   - На главной: `<a href="about.html">Подробнее обо мне</a>`
   - На about: `<a href="index.html">На главную</a>`

## Как сдать

1. Убедись, что файл `index.html` открывается в браузере без ошибок
2. Проверь все ссылки — они должны работать
3. Покажи результат на следующем занятии или отправь папку с проектом преподавателю

---

## Частые ошибки — проверь себя

- [ ] Закрыты все теги (`<p>` → `</p>`)
- [ ] Атрибуты в кавычках: `href="..."`, а не `href=...`
- [ ] `alt` у каждой картинки
- [ ] `<li>` только внутри `<ul>` или `<ol>`
- [ ] Файл сохранён с расширением `.html`, а не `.txt`
