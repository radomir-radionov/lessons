## 1. Введение: что такое HTML

### Как устроен веб

1. Браузер отправляет запрос на сервер
2. Сервер отдаёт файлы (HTML, CSS, изображения…)
3. Браузер **интерпретирует** файлы и показывает страницу

**HTML** описывает **структуру** страницы: заголовки, абзацы, ссылки, картинки. За внешний вид отвечает **CSS**, за интерактивность — **JavaScript**.

### Аналогия

| Часть      | Роль                                 |
| ---------- | ------------------------------------ |
| HTML       | Стены, двери — структура             |
| CSS        | Обои, мебель — оформление            |
| JavaScript | Кнопки, автоматика — интерактивность |

### Ключевые понятия

| Термин            | Определение                                                                       |
| ----------------- | --------------------------------------------------------------------------------- |
| **HTML**          | Язык разметки веб-страниц. Не язык программирования — только описывает структуру  |
| **Веб-страница**  | HTML-документ, который браузер отображает пользователю. Один файл = одна страница |
| **Разметка**      | Структурирование контента тегами: «это заголовок», «это ссылка»                   |
| **Браузер**       | Программа для просмотра страниц (Chrome, Firefox, Safari, Edge)                   |
| **Редактор кода** | Программа для написания кода. Мы используем **VS Code**                           |

## 3. Структура и разметка страницы

### Каркас HTML5

Скопируй и используй как отправную точку для любой страницы:

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Название страницы</title>
  </head>
  <body>
    <!-- Контент страницы -->
  </body>
</html>
```

### Элементы каркаса

| Элемент                  | Назначение                                             |
| ------------------------ | ------------------------------------------------------ |
| `<!DOCTYPE html>`        | Первая строка файла — сообщает браузеру, что это HTML5 |
| `<html lang="ru">`       | Корневой элемент. `lang` — язык страницы               |
| `<head>`                 | Служебная часть: метаданные, **не видна** на странице  |
| `<title>`                | Заголовок вкладки браузера                             |
| `<meta charset="UTF-8">` | Кодировка — без неё русский текст может «сломаться»    |
| `<meta name="viewport">` | Корректное отображение на телефонах                    |
| `<body>`                 | Всё, что **видит** пользователь                        |

> **Правило:** в `<head>` — информация **о** странице. В `<body>` — то, что **на** странице.

### Комментарии и вложенность

```html
<!-- Комментарий — не виден в браузере -->
<p>Текст с <strong>важным</strong> словом</p>
```

- Комментарий: `<!-- текст -->`
- Тег, открытый позже, закрывается раньше (вложенность)
- Отступы не влияют на отображение, но делают код читаемым

### Пример: первая страница

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Моя первая страница</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это моя первая HTML-страница.</p>
  </body>
</html>
```

## 4. HTML-теги и атрибуты

### Синтаксис элемента

```html
<имя_тега атрибут="значение">Содержимое</имя_тега>
```

| Понятие      | Пример                  | Описание                                     |
| ------------ | ----------------------- | -------------------------------------------- |
| Тег          | `<p>`                   | Метка типа элемента (в нижнем регистре)      |
| Элемент      | `<p>Текст</p>`          | Открывающий + содержимое + закрывающий тег   |
| Атрибут      | `href="..."`            | Дополнительная информация в открывающем теге |
| Void-элемент | `<img>`, `<br>`, `<hr>` | Без закрывающего тега и без текста внутри    |

### Основные теги

| Тег             | Назначение                          | Пример                                    |
| --------------- | ----------------------------------- | ----------------------------------------- |
| `<h1>`–`<h6>`   | Заголовки (на странице один `<h1>`) | `<h1>Главный заголовок</h1>`              |
| `<p>`           | Абзац                               | `<p>Текст абзаца.</p>`                    |
| `<a>`           | Ссылка                              | `<a href="https://google.com">Google</a>` |
| `<img>`         | Изображение                         | `<img src="photo.jpg" alt="Описание" />`  |
| `<ul>` + `<li>` | Маркированный список                | `<ul><li>Пункт</li></ul>`                 |
| `<ol>` + `<li>` | Нумерованный список                 | `<ol><li>Шаг 1</li></ol>`                 |
| `<strong>`      | Важный текст (жирный)               | `<strong>важно</strong>`                  |
| `<em>`          | Акцент (курсив)                     | `<em>очень</em>`                          |
| `<hr>`          | Горизонтальная линия-разделитель    | `<hr />`                                  |

### Ключевые атрибуты

| Атрибут  | Где     | Назначение                        | Пример                            |
| -------- | ------- | --------------------------------- | --------------------------------- |
| `href`   | `<a>`   | Адрес ссылки                      | `href="about.html"`               |
| `target` | `<a>`   | Как открыть ссылку                | `target="_blank"` — новая вкладка |
| `src`    | `<img>` | Путь к изображению                | `src="images/photo.jpg"`          |
| `alt`    | `<img>` | Описание картинки (обязательно!)  | `alt="Рыжий кот"`                 |
| `id`     | любой   | Уникальное имя (один на страницу) | `id="top"`                        |
| `class`  | любой   | Имя класса (можно повторять)      | `class="intro"`                   |

**Пути к файлам:**

- **Относительный** — от текущего файла: `images/photo.jpg`
- **Абсолютный (URL)** — полный адрес: `https://example.com/photo.jpg`

**`id` vs `class`:** `id` — как паспорт (уникальный), `class` — как фамилия (много элементов).

### Полный пример страницы

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Обо мне</title>
  </head>
  <body>
    <!-- Шапка -->
    <h1 id="top">Иван Иванов</h1>
    <p class="intro">Мне <strong>16 лет</strong>, я живу в <em>Москве</em>.</p>

    <hr />

    <!-- Секция: игры -->
    <h2>Мои любимые игры</h2>
    <ul>
      <li>Minecraft</li>
      <li>CS2</li>
      <li>Dota 2</li>
    </ul>

    <!-- Секция: ссылки -->
    <p>
      Мой любимый сайт:
      <a href="https://youtube.com" target="_blank">YouTube</a>
    </p>

    <hr />

    <img src="https://placehold.co/200x200" alt="Моё фото" />
    <p><a href="#top">Наверх</a></p>
  </body>
</html>
```

### Справочник: дополнительные теги

> Эти теги не обязательны на уроке, но пригодятся в практике и ДЗ.

| Тег      | Назначение                                                |
| -------- | --------------------------------------------------------- |
| `<div>`  | Блочный контейнер для группировки                         |
| `<span>` | Строчный контейнер внутри текста                          |
| `<br>`   | Перенос строки (не злоупотребляй — для отступов есть CSS) |

**Блочные** (`<p>`, `<h1>`, `<ul>`) — с новой строки, на всю ширину.  
**Строчные** (`<a>`, `<strong>`, `<img>`) — в одной строке с текстом.

## 5. Итог урока

### Что мы узнали

1. **HTML** — язык разметки, «скелет» веб-страницы
2. **Структура:** `DOCTYPE` → `html` → `head` + `body`
3. **Основные теги:** заголовки, абзацы, ссылки, списки, изображения
4. **Атрибуты:** `href`, `src`, `alt`, `target`, `id`, `class`
5. **Семантика** — теги несут смысл, а не только внешний вид

2. Какой тег — ссылка? Какой атрибут задаёт адрес?
3. Зачем нужен `alt` у `<img>`?
4. Чем `<ul>` отличается от `<ol>`?
5. В чём разница между `id` и `class`?
