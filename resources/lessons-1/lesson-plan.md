# План занятия — Урок 1: Знакомство с HTML

**Модуль:** HTML, CSS, Git  
**Длительность:** 60 минут  
**Материалы:** [lesson.md](lesson.md) · [tasks.md](tasks.md) · [homework.md](homework.md)

---

## Цели урока

К концу занятия ученик сможет:

1. Настроить рабочее окружение (редактор, браузер, папка проекта)
2. Создать HTML-файл с правильной структурой документа
3. Использовать основные HTML-теги и атрибуты
4. Открыть и просмотреть свою страницу в браузере

**Результат:** ученик создаёт первую HTML-страницу и открывает её в браузере.

## Краткое содержание блоков

### Блок 1 — Введение (0–5 мин)

- Что такое веб и HTML
- HTML vs CSS
- Ключевые определения: HTML, веб-страница, разметка, браузер, редактор кода

### Блок 2 — Рабочее окружение (5–15 мин)

- Установка VS Code, создание папки `my-first-site`
- Создание `index.html`, открытие в браузере
- Live Server, DevTools (вкладка Elements) — кратко
- Демо: сохранение файла → обновление страницы

### Блок 3 — Структура страницы (15–22 мин)

- Каркас HTML5: `DOCTYPE`, `html`, `head`, `body`
- Мета-теги: `charset`, `viewport`
- Комментарии, вложенность тегов
- Ученик копирует каркас и меняет `<title>`

### Блок 4 — Теги и атрибуты (22–32 мин)

- Синтаксис элемента: тег, атрибут, void-элементы
- Основные теги: `h1`–`h6`, `p`, `a`, `img`, `ul`/`ol`/`li`, `strong`, `em`
- Ключевые атрибуты: `href`, `src`, `alt`, `target`
- Один полный пример страницы (остальные теги — по ходу практики)

### Блок 5 — Практика (32–55 мин)

- Задачи 1–5 из [tasks.md](tasks.md) (~23 мин)
- Если ученик быстрый — все 5 задач; если медленный — минимум задачи 1–3, остальное в ДЗ

### Блок 6 — Итог (55–60 мин)

- Резюме, 4 контрольных вопроса
- Выдача домашнего задания «Моя визитка»

## Частые проблемы (проговорить при настройке)

| Проблема                             | Решение                                                                       |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| Файл сохранился как `index.html.txt` | В VS Code проверить имя в Explorer; включить отображение расширений в системе |
| Кракозябры вместо русского текста    | Добавить `<meta charset="UTF-8">` в `<head>`                                  |
| Live Server не запускается           | Открыть файл двойным кликом в проводнике или перезапустить VS Code            |
| Картинка не отображается             | Проверить путь в `src` и регистр букв в имени файла                           |
