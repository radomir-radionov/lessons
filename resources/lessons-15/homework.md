# Домашнее задание — Урок 15

**Задание:** «Продолжение финального проекта»  
**Время:** ~45–60 минут (между уроками 15 и 16)  
**Папка:** `final-project/`

---

## Описание

Между уроками 15 и 16 нужно **доделать контент и подготовить проект** к этапу 2 (layout, адаптив, анимации). Это не отдельная работа — это продолжение финального проекта.

---

## Требования

### 1. Контент

- [ ] Замени все заглушки («Lorem», «Текст») на **реальные** заголовки и описания по теме
- [ ] Hero: цепляющий заголовок + подзаголовок + текст на кнопке CTA
- [ ] Секция «О продукте»: минимум 2 абзаца осмысленного текста
- [ ] 3 карточки преимуществ с уникальными заголовками и описаниями

### 2. Изображения

- [ ] Добавь минимум **4 изображения** в папку `images/`
- [ ] Hero или «О продукте» — 1 изображение
- [ ] Галерея — минимум 3 изображения
- [ ] Все пути в `src` корректные, у каждого `img` есть `alt`

> Можно использовать [placehold.co](https://placehold.co), [unsplash.com](https://unsplash.com) или свои фото.

### 3. Дополнительные стили (без Flex/Grid пока)

- [ ] Задай фоновый цвет или градиент для hero-секции
- [ ] Стилизуй кнопку CTA (padding, border-radius, цвет из переменных)
- [ ] Добавь отступы секциям (`padding` сверху и снизу)
- [ ] Ограничь ширину контента (например, `max-width: 1200px; margin: 0 auto`)

### 4. Git

- [ ] Сделай минимум **2 коммита** с осмысленными сообщениями, например:
  - `Add real content and images`
  - `Style hero section and CTA button`
- [ ] Если ещё не сделал — запушь проект на GitHub

---

## Пример коммитов

```bash
git add .
git commit -m "Add real content and gallery images"
git commit -m "Style hero and section spacing"
git push
```

## Критерии готовности к уроку 16

| Критерий | Статус |
| -------- | ------ |
| Весь контент заполнен (не заглушки) | ☐ |
| 4+ изображения в `images/` | ☐ |
| Hero и кнопка CTA стилизованы | ☐ |
| Секции имеют вертикальные отступы | ☐ |
| 4+ коммита в Git всего | ☐ |
| Проект на GitHub (желательно) | ☐ |

---

## Что НЕ нужно делать до урока 16

- ❌ Media queries и адаптив — разберём на уроке
- ❌ Flexbox и Grid для раскладки — разберём на уроке
- ❌ Анимации — разберём на уроке
- ❌ JavaScript для формы — не обязательно

---

## Частые ошибки — проверь себя

- [ ] Изображения лежат в `images/`, а не на рабочем столе с абсолютным путём
- [ ] `alt` у каждой картинки описывает содержимое
- [ ] Кнопка CTA — это `<a>` или `<button>`, а не просто текст
- [ ] Коммиты с понятными сообщениями, не «fix» и «update»
- [ ] `index.html` открывается без битых картинок

---

## Как подготовиться к уроку 16

1. Открой проект в VS Code
2. Убедись, что `git status` чистый (всё закоммичено)
3. Имей под рукой ссылку на GitHub-репозиторий
4. Продумай, какие секции будешь верстать на Flex, а какие на Grid
