## Задача 1 — «План и тема» (8 мин)

### Задание

1. Выбери тему лендинга из [lesson.md](lesson.md#1-бриф-финального-проекта) или предложи свою (согласуй с преподавателем)
2. На бумаге или в заметках набросай схему: какие секции, в каком порядке
3. Составь список контента: заголовки, тексты (хотя бы черновик), какие картинки нужны
4. Создай файл `README.md` с названием проекта, темой и своим именем

### Критерии выполнения

- [ ] Тема выбрана и зафиксирована в README
- [ ] Есть схема из 7 секций (можно фото/скрин наброска)
- [ ] Список контента: минимум заголовок hero и 3 преимущества
- [ ] README содержит: название, автор, краткое описание

### Подсказка

```markdown
# Coffee House

**Тема:** Лендинг кофейни  
**Автор:** Мария Сидорова

## Описание
Сайт для привлечения гостей в кофейню. CTA — «Забронировать столик».
```

## Задача 3 — «HTML-разметка всех секций» (20 мин)

### Задание

В `index.html` разметь **все 7 секций** с семантическими тегами:

1. `<header>` — логотип + `<nav>` с якорными ссылками
2. `<section id="hero">` — h1, подзаголовок, кнопка-ссылка
3. `<section id="about">` — заголовок, текст, `<img>`
4. `<section id="features">` — заголовок + 3 `<article>` или `<div class="feature-card">`
5. `<section id="gallery">` — заголовок + 3–6 `<img>`
6. `<section id="contact">` — `<form>` с полями: имя, email, textarea, button
7. `<footer>` — контакты, год, копирайт

Добавь `id` у секций для якорных ссылок в nav.

### Критерии выполнения

- [ ] Использованы `header`, `main`, `section`, `footer`
- [ ] Все 7 секций присутствуют с контентом (не пустые)
- [ ] Навигация ссылается на `#hero`, `#about`, `#features` и т.д.
- [ ] Форма содержит `<label>`, `<input>`, `<textarea>`, `<button type="submit">`
- [ ] У всех `<img>` есть атрибут `alt`
- [ ] HTML-комментарии перед каждой секцией

### Подсказка

```html
<body>
  <header class="header">
    <a href="#" class="logo">Coffee House</a>
    <nav class="nav">
      <a href="#about">О нас</a>
      <a href="#features">Меню</a>
      <a href="#contact">Контакты</a>
    </nav>
  </header>

  <main>
    <!-- Hero -->
    <section id="hero" class="hero">...</section>
    <!-- ... остальные секции -->
  </main>

  <footer class="footer">...</footer>
</body>
```

## Задача 4 — «Базовый CSS» (10 мин)

### Задание

1. Создай `css/reset.css` — минимальный сброс (`margin: 0`, `box-sizing`, сброс списков)
2. В `css/style.css` задай:
   - CSS-переменные в `:root` (основной цвет, цвет текста, фон, шрифт)
   - Базовую типографику: `body` font-family, line-height, color
   - Стили для `a` (цвет, без подчёркивания или с hover)
3. Подключи оба файла в `index.html`
4. Коммит: `git commit -m "Add HTML markup and base styles"`

### Критерии выполнения

- [ ] `reset.css` и `style.css` подключены в `<head>`
- [ ] Минимум 4 CSS-переменные в `:root`
- [ ] Текст на странице читаемый (задан шрифт и цвет)
- [ ] Ссылки визуально отличаются от обычного текста
- [ ] Второй коммит в Git с осмысленным сообщением

### Подсказка

```css
:root {
  --color-primary: #6366f1;
  --color-text: #1e293b;
  --color-bg: #ffffff;
  --font-main: system-ui, sans-serif;
}

body {
  font-family: var(--font-main);
  color: var(--color-text);
  line-height: 1.6;
}
```

## Задача 5 — «Проверка и push (бонус)» (5 мин)

### Задание

1. Открой `index.html` в браузере — пройдись по якорным ссылкам
2. Проверь `git log --oneline` — минимум 2 коммита
3. Если успеваешь — создай репозиторий на GitHub и выполни `git push`

### Критерии выполнения

- [ ] Страница открывается, все секции видны
- [ ] Якорные ссылки прокручивают к секциям
- [ ] В истории Git минимум 2 коммита
- [ ] (Бонус) Проект запушен на GitHub

### Подсказка

```bash
git remote add origin https://github.com/username/final-project.git
git push -u origin main
```
