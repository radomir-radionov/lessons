# План занятия — Урок 15: Финальный проект (часть 1)

**Модуль:** HTML, CSS, Git  
**Длительность:** 60 минут  
**Формат:** проектное занятие  
**Материалы:** [lesson.md](lesson.md) · [tasks.md](tasks.md) · [homework.md](homework.md)

---

## Цели урока

К концу занятия ученик сможет:

1. Спланировать структуру финального проекта и выбрать тему лендинга
2. Инициализировать Git-репозиторий и сделать первые коммиты
3. Сверстать полную HTML-разметку всех секций сайта
4. Подключить базовые CSS-стили: сброс, типографика, цвета

**Результат:** ученик имеет репозиторий с размеченным лендингом и базовыми стилями — готов к доработке на уроке 16.

## Краткое содержание блоков

### Блок 1 — Бриф (0–10 мин)

- Лендинг на 5–6 секций: hero, о продукте, преимущества, галерея, форма, footer
- Обязательные технологии: HTML, CSS, Flex/Grid (на уроке 16), Git
- Критерии оценки — таблица в lesson.md

### Блок 2 — Планирование (10–18 мин)

- Выбор темы: курс, приложение, услуга, портфолио
- Схема секций на бумаге или в Figma/Excalidraw
- Список контента: тексты, изображения

### Блок 3 — Git и структура (18–25 мин)

- Папка `final-project/`, `index.html`, `css/`, `images/`
- `git init`, `.gitignore`, коммит «Initial structure»

### Блок 4 — HTML (25–45 мин)

- Семантика: `header`, `nav`, `main`, `section`, `footer`
- Все секции с заголовками и контентом-заглушками

### Блок 5 — Базовый CSS (45–55 мин)

- CSS-переменные для цветов
- Шрифты, базовые отступы, `box-sizing`

### Блок 6 — Итог (55–60 мин)

- Промежуточная проверка по чеклисту
- ДЗ: доделать контент и подготовиться к уроку 16
