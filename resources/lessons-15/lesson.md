## 1. Бриф финального проекта

### Задача

Создать **одностраничный лендинг** (landing page) — промо-сайт для продукта, услуги, курса или личного портфолио. Это итоговая работа модуля HTML & CSS: ты применяешь всё, что изучил за 14 уроков.

### Темы на выбор (одна)

| Тема | Пример |
| ---- | ------ |
| Онлайн-курс | «Школа веб-разработки для начинающих» |
| Мобильное приложение | «Приложение для учёта расходов» |
| Локальный бизнес | «Кофейня на Немиге» |
| Личное портфолио | «Портфолио веб-разработчика» |
| Стартап / SaaS | «Сервис для планирования задач» |

Тема должна быть **понятной** и позволять заполнить все секции реальным (или правдоподобным) контентом.

### Обязательные секции лендинга

1. **Header** — логотип/название + навигация (3–5 ссылок-якорей)
2. **Hero** — главный экран: заголовок, подзаголовок, CTA-кнопка
3. **О продукте / О себе** — текст + изображение
4. **Преимущества** — минимум 3 карточки с иконкой или картинкой
5. **Галерея / Примеры работ** — 3–6 изображений
6. **Форма обратной связи** — имя, email, сообщение, кнопка (разметка на этом уроке, стилизация — на уроке 16)
7. **Footer** — контакты, копирайт, ссылки

### Технологии

| Разрешено | Запрещено на этапе 1 |
| --------- | -------------------- |
| HTML5, семантические теги | JavaScript (кроме опционального бонуса) |
| CSS (свои файлы) | Bootstrap / Tailwind (финальный проект — на чистом CSS) |
| Git, GitHub | Копирование чужого готового шаблона целиком |
| Изображения (локальные или placeholder) | CMS, WordPress |

---

### Определения и понятия

#### Лендинг (landing page)

**Лендинг** — одностраничный сайт с чёткой целью: познакомить с продуктом и побудить к действию (записаться, купить, связаться).

#### CTA (Call to Action)

**CTA** — призыв к действию: кнопка или ссылка («Записаться», «Попробовать бесплатно», «Связаться»).

#### Якорная ссылка

**Якорная ссылка** — ссылка на секцию той же страницы: `<a href="#about">О нас</a>` → `<section id="about">`.

#### Milestone (этап проекта)

**Milestone** — контрольная точка проекта. Этап 1 (урок 15): разметка и базовые стили. Этап 2 (урок 16): layout, адаптив, анимации, сдача.

## 3. Рекомендуемая структура файлов

```
final-project/
├── index.html          # Главная страница
├── README.md           # Описание проекта, тема, автор
├── .gitignore          # node_modules, .DS_Store и т.д.
├── css/
│   ├── reset.css       # Сброс стилей (или normalize)
│   ├── variables.css   # CSS-переменные (опционально, можно в style.css)
│   └── style.css       # Основные стили
├── images/
│   ├── hero.jpg
│   ├── about.jpg
│   └── gallery-1.jpg
└── fonts/              # Если подключаешь кастомные шрифты
```

### Порядок подключения CSS в `index.html`

```html
<head>
  <link rel="stylesheet" href="css/reset.css" />
  <link rel="stylesheet" href="css/style.css" />
</head>
```

### Минимальный `.gitignore`

```
.DS_Store
Thumbs.db
*.log
node_modules/
```

---

### Определения и понятия

#### README

**README** — файл с описанием проекта в корне репозитория. Первое, что видит проверяющий на GitHub.

#### .gitignore

**`.gitignore`** — файл со списком путей, которые Git не должен отслеживать (системные файлы, секреты, зависимости).

#### CSS-переменные (custom properties)

**CSS-переменные** — значения, заданные один раз и переиспользуемые:

```css
:root {
  --color-primary: #6366f1;
  --color-text: #1e293b;
  --font-main: system-ui, sans-serif;
}
```

#### reset.css

**reset.css** — файл, обнуляющий стандартные отступы браузера для предсказуемой вёрстки.
