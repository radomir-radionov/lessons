## 1. Бриф финального проекта

### Задача

Создать **одностраничный лендинг** — промо-сайт для продукта, услуги, курса или портфолио. Итоговая работа модуля HTML & CSS.

### Темы на выбор (одна)

| Тема | Пример |
| ---- | ------ |
| Онлайн-курс | «Школа веб-разработки для начинающих» |
| Мобильное приложение | «Приложение для учёта расходов» |
| Локальный бизнес | «Кофейня на Немиге» |
| Личное портфолио | «Портфолио веб-разработчика» |
| Стартап / SaaS | «Сервис для планирования задач» |

Тема должна позволять заполнить все секции реальным (или правдоподобным) контентом.

### Обязательные секции

| # | Секция | Содержимое |
| - | ------ | ---------- |
| 1 | **Header** | Логотип/название + навигация (3–5 якорей) |
| 2 | **Hero** | Заголовок, подзаголовок, CTA-кнопка |
| 3 | **О продукте** | Текст + изображение |
| 4 | **Преимущества** | Минимум 3 карточки |
| 5 | **Галерея** | 3–6 изображений |
| 6 | **Форма** | Имя, email, сообщение, кнопка (разметка сейчас, стили — на этапе 2) |
| 7 | **Footer** | Контакты, копирайт, ссылки |

### Технологии

| Разрешено | Запрещено на этапе 1 |
| --------- | -------------------- |
| HTML5, семантические теги | JavaScript (кроме опционального бонуса) |
| Свой CSS (отдельные файлы) | Bootstrap / Tailwind |
| Git, GitHub | Копирование чужого шаблона целиком |
| Локальные или placeholder-изображения | CMS, WordPress |

### Ключевые понятия

| Термин | Определение |
| ------ | ----------- |
| **Лендинг** | Одностраничный сайт с целью: познакомить и побудить к действию |
| **CTA** | Призыв к действию: «Записаться», «Попробовать бесплатно» |
| **Якорная ссылка** | `<a href="#about">` → `<section id="about">` |
| **Milestone** | Контрольная точка проекта (этап 1 / этап 2) |

## 3. Рекомендуемая структура файлов

```
final-project/
├── index.html          # Главная страница
├── README.md           # Описание проекта, тема, автор
├── .gitignore          # node_modules, .DS_Store и т.д.
├── css/
│   ├── reset.css       # Сброс стилей
│   └── style.css       # Основные стили (+ переменные)
├── images/
│   ├── hero.jpg
│   ├── about.jpg
│   └── gallery-1.jpg
└── fonts/              # Опционально
```

### Подключение CSS

```html
<head>
  <link rel="stylesheet" href="css/reset.css" />
  <link rel="stylesheet" href="css/style.css" />
</head>
```

### Минимальный `.gitignore`

```
.DS_Store
Thumbs.db
*.log
node_modules/
```

### CSS-переменные

```css
:root {
  --color-primary: #6366f1;
  --color-text: #1e293b;
  --font-main: system-ui, sans-serif;
}
```

### README.md — шаблон

```markdown
# Название проекта

**Тема:** Онлайн-курс веб-разработки
**Автор:** Иван Иванов
**Модуль:** HTML, CSS, Git

## Описание
Кратко: для кого сайт, какая цель.

## Секции
Hero, О курсе, Преимущества, Галерея, Форма, Footer

## Как открыть
Открыть index.html в браузере или через Live Server.
```

### Git на старте

```bash
cd final-project
git init
git add .
git commit -m "Initial structure"
```

| Термин | Определение |
| ------ | ----------- |
| **README** | Описание проекта в корне репозитория |
| **.gitignore** | Список путей, которые Git не отслеживает |
| **reset.css** | Сброс стандартных отступов браузера |
| **CSS-переменная** | Переиспользуемое значение в `:root` |

## 4. Итог урока

### Что должно быть готово

1. Папка `final-project/` с файловой структурой
2. Git-репозиторий с коммитами
3. Полная HTML-разметка всех секций

### Вопросы для самопроверки

1. Все ли 7 секций размечены в HTML?
2. Использованы ли семантические теги (`header`, `main`, `section`, `footer`)?

4. Есть ли README с описанием темы?
5. Сделан ли хотя бы один коммит с осмысленным сообщением?
