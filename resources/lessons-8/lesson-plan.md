## Цели урока

К концу занятия ученик сможет:

1. Создавать HTML-формы с правильной структурой (`form`, `label`, `input`, `textarea`, `select`, `button`)
2. Использовать разные типы полей (`text`, `email`, `password`, `number`, `checkbox`, `radio`)
3. Применять атрибуты `required`, `placeholder`, `name` и группировать поля через `fieldset`
4. Стилизовать поля ввода с помощью CSS

**Результат:** ученик создаёт стилизованную форму регистрации с валидацией и аккуратным оформлением.

## Краткое содержание блоков

### Блок 1 — Основы форм (0–8 мин)

- Форма — способ отправки данных на сервер
- `<form action="..." method="post">` — куда и как отправлять
- На уроке `action="#"` (заглушка, без бэкенда)
- Атрибут `name` — имя поля при отправке

### Блок 2 — Поля ввода (8–18 мин)

- `<input type="text">` — текст
- `type="email"`, `type="password"`, `type="number"`, `type="tel"`
- `type="checkbox"` — галочка; `type="radio"` — выбор одного из группы
- `placeholder` — подсказка внутри поля (не заменяет label!)

### Блок 3 — label (18–24 мин)

- `<label for="email">` связан с `<input id="email">`
- Клик по label фокусирует поле — удобно и доступно
- Каждое поле должно иметь подпись

### Блок 4 — textarea, select, button (24–30 мин)

- `<textarea>` — многострочный текст
- `<select>` + `<option>` — выпадающий список
- `<button type="submit">` — отправка; `type="reset"` — сброс

### Блок 5 — required и fieldset (30–32 мин)

- `required` — обязательное поле (браузерная валидация)
- `<fieldset>` + `<legend>` — группировка связанных полей

### Блок 6 — Стилизация (32–38 мин)

- `width: 100%`, `padding`, `border`, `border-radius`
- `box-sizing: border-box` на input
- `:focus` — подсветка активного поля
- Стилизация `select` и `textarea` аналогично `input`

### Блок 7 — Практика (38–55 мин)

- Задачи 1–5 из [tasks.md](tasks.md) — пошаговая сборка формы регистрации
- Минимум: задачи 1–3; 4–5 — по темпу

### Блок 8 — Итог (55–60 мин)

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Форма «отправляется» и страница перезагружается | `action="#"` или `event.preventDefault()` (JS — позже) |
| Label не фокусирует поле | Проверить совпадение `for` и `id` |
| Radio выбираются все | У всех radio в группе одинаковый `name` |
| Поля вылезают за контейнер | `box-sizing: border-box; width: 100%` |
| `required` не срабатывает | Кнопка должна быть `type="submit"`, поле внутри `<form>` |
| Checkbox/radio не стилизуются | Нормально — для кастомных чекбоксов нужны продвинутые приёмы |
