## Цели урока

К концу занятия ученик сможет:

1. Инициализировать npm-проект (`npm init`) и понимать `package.json`
2. Установить зависимости через `npm install`
3. Писать стили на Sass: переменные и вложенность
4. Собрать проект через Parcel (`npx parcel index.html`)

**Результат:** ученик создаёт проект с `styles.scss`, переменными цветов и собирает его в `dist/`.

## Краткое содержание блоков

### Блок 1 — npm и Node.js (0–10 мин)

- Node.js — среда выполнения JavaScript вне браузера
- npm — менеджер пакетов, устанавливает библиотеки и инструменты
- `npm init -y`, структура `package.json`
- `node_modules/`, `.gitignore`

### Блок 2 — Sass (10–20 мин)

- CSS-препроцессор: пишем `.scss`, получаем `.css`
- Зачем: переменные, вложенность, импорты
- Синтаксис SCSS (фигурные скобки, как CSS)

### Блок 3 — Переменные и вложенность (20–27 мин)

- `$variable-name: value;`
- Вложенность: `.header { .logo { ... } }`
- `&` для псевдоклассов и БЭМ-модификаторов

### Блок 4 — Parcel (27–32 мин)

- Сборщик: компилирует Sass, оптимизирует, создаёт `dist/`
- `npm install --save-dev parcel`
- `npx parcel index.html` — dev-сервер
- `npx parcel build index.html` — продакшен-сборка

### Блок 5 — Практика (32–55 мин)

- Минимум: задачи 1–4; задача 5 — по темпу или в ДЗ

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| `npm: command not found` | Установить Node.js с [nodejs.org](https://nodejs.org/) |
| Стили не применяются | Подключить `.scss` в HTML, Parcel компилирует автоматически |
| `node_modules` в Git | Добавить в `.gitignore` |
| Ошибка в Sass | Проверить `$` у переменных, закрытые скобки |
| Parcel не запускается | `npx parcel index.html` из корня проекта |
