# План занятия — Урок 3: Практика HTML & CSS

**Модуль:** HTML, CSS, Git  
**Длительность:** 60 минут  
**Формат:** практический (короткая теория + верстка)  
**Материалы:** [lesson.md](lesson.md) · [tasks.md](tasks.md) · [homework.md](homework.md)

---

## Цели урока

К концу занятия ученик сможет:

1. Собрать страницу из семантических блоков: `header`, `main`, `section`, `footer`
2. Сверстать шапку с логотипом и меню, секцию из 3 карточек и подвал
3. Применить CSS: отступы, цвета, типографика, блочная модель
4. Найти и исправить типичные ошибки вёрстки по чеклисту

**Результат:** одностраничный макет «шапка → карточки → подвал» в `index.html` + `style.css`.

## Краткое содержание блоков

### Блок 1 — HTML (0–10 мин)

Каркас HTML5, семантика (`header`, `nav`, `main`, `footer`), ссылки, списки, `alt`, БЭМ.

### Блок 2 — CSS (10–18 мин)

`<link rel="stylesheet">`, селекторы, `color`, `background`, `font-family`, box model (`margin`, `padding`, `border`).

### Блок 3 — Паттерны (18–25 мин)

Шапка (логотип + меню), 3 карточки, подвал, контейнер `.container` с `max-width`.

### Блок 4 — Ошибки (25–32 мин)

Чеклист из `lesson.md` §4, демо в DevTools.

### Блок 5 — Практика (32–55 мин)

Задачи 1–6 из [tasks.md](tasks.md). Минимум на уроке: 1–4; 5–6 — по темпу или в ДЗ.

### Блок 6 — Итог (55–60 мин)

Резюме, 4 вопроса, выдача ДЗ «Мини-лендинг».

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Стили не применяются | Проверить путь в `<link href="style.css">` |
| Меню в колонку | `display: flex` на `.header__inner` |
| Текст у края экрана | `padding` у `.container` |
| Картинка вылезает | `img { max-width: 100%; }` |
| Бессмысленные классы | БЭМ: `header__logo`, `card__title` |
