## 1. Шпаргалка HTML

### Каркас документа

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Название страницы</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <!-- контент -->
  </body>
</html>
```

| Элемент           | Назначение                              |
| ----------------- | --------------------------------------- |
| `<!DOCTYPE html>` | Объявление HTML5                        |
| `<head>`          | Мета-информация (не видна на странице)  |
| `<body>`          | Всё, что видит пользователь             |
| `<title>`         | Заголовок вкладки                       |

### Основные теги

| Тег               | Назначение                                    |
| ----------------- | --------------------------------------------- |
| `h1`–`h6`         | Заголовки (на странице один `h1`)             |
| `p`               | Абзац                                         |
| `a`               | Ссылка (`href`, `target="_blank"`)            |
| `img`             | Изображение (`src` + обязательный `alt`)      |
| `ul` / `ol` / `li`| Маркированный / нумерованный список           |
| `strong` / `em`   | Важное / акцент                               |

### Семантические теги

| Тег       | Назначение                              |
| --------- | --------------------------------------- |
| `header`  | Шапка сайта или секции                  |
| `nav`     | Блок навигации (меню)                   |
| `main`    | Основной контент (один на страницу)     |
| `section` | Логическая секция с заголовком          |
| `article` | Самостоятельный блок (карточка)         |
| `footer`  | Подвал                                  |

### БЭМ — именование классов

```
блок__элемент--модификатор
```

Примеры: `header`, `header__logo`, `header__nav`, `header__link`, `header__link--active`.

## 2. Шпаргалка CSS

### Подключение

```html
<link rel="stylesheet" href="style.css" />
```

### Селекторы

| Селектор  | Пример          | Что выбирает                    |
| --------- | --------------- | ------------------------------- |
| По тегу   | `p { }`         | Все абзацы                      |
| По классу | `.card { }`     | `class="card"`                  |
| По id     | `#top { }`      | `id="top"` (один на страницу)   |
| Потомок   | `.header a { }` | Ссылки внутри `.header`         |

### Свойства и box model

| Свойство                       | Назначение                              |
| ------------------------------ | --------------------------------------- |
| `color` / `background-color`   | Цвет текста и фона                      |
| `font-family` / `font-size`    | Шрифт и размер                          |
| `margin`                       | Внешний отступ (между блоками)          |
| `padding`                      | Внутренний отступ (внутри блока)        |
| `border`                       | Рамка                                   |
| `max-width` + `margin: 0 auto` | Центрирование контейнера                |

### Сброс и контейнер

```css
*, *::before, *::after { box-sizing: border-box; }
body { margin: 0; }

.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
```

## 3. Паттерны макета

### Схема страницы

```
┌─────────────────────────────────────┐
│  HEADER: логотип + меню             │
├─────────────────────────────────────┤
│  MAIN → SECTION: 3 карточки         │
├─────────────────────────────────────┤
│  FOOTER: копирайт + ссылки          │
└─────────────────────────────────────┘
```

### Шапка — логотип + меню

Структура: `header` → `.container.header__inner` → `a.header__logo` + `nav.header__nav` с `.header__link`.

Ключевые стили: белый фон, `border-bottom`, `display: flex` + `justify-content: space-between` на `.header__inner`.

> Полные примеры кода — в [tasks.md](tasks.md).

### Секция из 3 карточек

Структура: `section.cards` → `.container` → `h2.cards__title` → `.cards__grid` → 3× `article.card`.

В каждой карточке: `h3.card__title`, `p.card__text`, `a.card__link`.

```css
.cards__grid { display: flex; gap: 24px; }
.card { flex: 1; padding: 24px; border: 1px solid #e0e0e0; }
```

### Подвал

Структура: `footer.footer` → `.container.footer__inner` → `p.footer__copy` + `nav.footer__nav`.

Ключевые стили: тёмный фон (`#1f2937`), светлый текст, контрастные `.footer__link`.

## 4. Чеклист частых ошибок

### HTML

- [ ] Закрыты все теги
- [ ] Атрибуты в кавычках: `class="header"`
- [ ] У каждого `<img>` есть `alt`
- [ ] `<li>` только внутри `<ul>` или `<ol>`
- [ ] Один `<main>` на страницу
- [ ] Заголовки по порядку: `h1` → `h2` → `h3`
- [ ] Ссылки с рабочим `href`

### CSS

- [ ] `style.css` подключён в `<head>`
- [ ] Классы по БЭМ, не `div1` / `block2`
- [ ] У `body` сброшен отступ: `margin: 0`
- [ ] Картинки: `img { max-width: 100%; height: auto; }`
- [ ] Контрастный текст на фоне

### Макет

- [ ] Шапка, контент и подвал визуально отделены
- [ ] Карточки единообразны (отступы, шрифты, рамка)
- [ ] Меню не слипается с логотипом
- [ ] Контент не прилипает к краям (`padding` у контейнера)

### Инструменты

- [ ] Страница открывается в браузере
- [ ] CSS обновляется после сохранения (F5 / Live Server)
- [ ] DevTools (F12) → структура совпадает с задумкой
