## 1. Введение в CSS Grid

### Что такое CSS Grid

**CSS Grid Layout** — система вёрстки для создания **двумерных сеток**: строк и колонок одновременно. Ты задаёшь структуру сетки на контейнере, а дочерние элементы автоматически размещаются в ячейках.

На [уроке 5](../lessons-5/) (если проходили) мы изучали **Flexbox** — он управляет элементами в **одном направлении** (ряд или колонка). Grid управляет **обоими направлениями** сразу.

### Аналогия

- **Flexbox** — расстановка книг на одной полке (в ряд или в столбик)
- **Grid** — книжный шкаф с полками и секциями (строки и колонки)

### Базовый пример

```html
<div class="grid">
  <div class="grid__item">1</div>
  <div class="grid__item">2</div>
  <div class="grid__item">3</div>
  <div class="grid__item">4</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 16px;
}
```

Результат: 4 элемента в сетке 2×2.

### Grid-контейнер и grid-элементы

| Термин | Что это |
| ------ | ------- |
| **Grid-контейнер** | Родитель с `display: grid` |
| **Grid-элемент** | Прямой потомок контейнера |
| **Grid-линия** | Разделитель между строками/колонками |
| **Grid-ячейка** | Пересечение строки и колонки |
| **Grid-область** | Прямоугольник из нескольких ячеек |

---

### Определения и понятия

#### CSS Grid Layout

**CSS Grid Layout** — модуль CSS для создания двумерных сеток. Позволяет задавать строки и колонки, размещать элементы по ячейкам и областям.

#### Grid-контейнер (grid container)

**Grid-контейнер** — элемент с `display: grid` или `display: inline-grid`. Его прямые потомки становятся grid-элементами.

#### Grid-элемент (grid item)

**Grid-элемент** — прямой дочерний элемент grid-контейнера. Размещается в ячейках сетки.

#### Двумерная сетка

**Двумерная сетка** — раскладка, где элементы позиционируются и по горизонтали (колонки), и по вертикали (строки) одновременно.

## 2. grid-template-columns и rows

### Задание колонок

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
}
```

Три колонки: фиксированная 200px и две гибкие.

### Единица `fr` (fraction)

**`fr`** — доля свободного пространства. Если задано `1fr 1fr 1fr`, каждая колонка получает треть доступной ширины.

```css
.grid {
  grid-template-columns: 1fr 1fr 1fr; /* три равные колонки */
}
```

`fr` удобнее процентов: не нужно считать `33.333%`, и `fr` учитывает `gap`.

### Функция `repeat()`

```css
grid-template-columns: repeat(3, 1fr);
/* то же, что: 1fr 1fr 1fr */

grid-template-columns: repeat(4, 100px);
/* четыре колонки по 100px */
```

### Задание строк

```css
.grid {
  grid-template-rows: auto 1fr auto;
}
```

- `auto` — высота по содержимому
- `1fr` — занимает оставшееся пространство

### Свойство `gap`

**`gap`** — отступ между ячейками сетки (между строками и колонками):

```css
.grid {
  gap: 16px;           /* одинаковый отступ */
  gap: 16px 24px;      /* строки 16px, колонки 24px */
  row-gap: 16px;        /* только между строками */
  column-gap: 24px;    /* только между колонками */
}
```

> Раньше использовали `grid-gap` — сейчас пиши просто `gap`.

### Полный пример: сетка карточек

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

.card {
  background: white;
  border-radius: 8px;
  padding: 16px;
}
```

6 карточек автоматически выстроятся в 2 ряда по 3.

---

### Определения и понятия

#### `grid-template-columns`

**`grid-template-columns`** — свойство grid-контейнера, задающее количество и размеры колонок сетки.

#### `grid-template-rows`

**`grid-template-rows`** — свойство grid-контейнера, задающее количество и размеры строк сетки.

#### `fr` (fraction)

**`fr`** — единица CSS Grid, обозначающая долю свободного пространства. `1fr` = одна равная часть.

#### `repeat()`

**`repeat()`** — CSS-функция для сокращённой записи повторяющихся значений: `repeat(3, 1fr)` = `1fr 1fr 1fr`.

#### `gap`

**`gap`** — отступ между ячейками grid- (и flex-) сетки. Заменяет устаревшие `grid-gap` / `grid-row-gap` / `grid-column-gap`.

## 3. Линии сетки и grid-area

### Нумерация линий

Grid-линии нумеруются с **1** (не с 0):

```
Линии колонок:  1    2    3    4
               | 1  | 2  | 3  |
Линии строк:   1 ---+----+----+
               2 ---+----+----+
               3 ---+----+----+
```

### Размещение по линиям

```css
.item {
  grid-column: 1 / 3;  /* от линии 1 до линии 3 (2 колонки) */
  grid-row: 1 / 2;     /* первая строка */
}
```

Сокращение:

```css
.item {
  grid-column: span 2; /* занять 2 колонки */
}
```

### grid-template-areas

Удобный способ задать **именованные области** для макетов страниц:

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  min-height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }
```

Каждая строка в `grid-template-areas` — это ряд сетки. Повторяющееся имя (`header header`) означает, что область занимает несколько колонок.

### HTML для макета

```html
<div class="layout">
  <header class="header">Шапка</header>
  <aside class="sidebar">Меню</aside>
  <main class="content">Контент</main>
  <footer class="footer">Подвал</footer>
</div>
```

### Вложенные сетки

Grid-элемент может сам быть grid-контейнером:

```css
.main {
  grid-area: content;
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}
```

Внешняя сетка — макет страницы. Внутренняя — сетка виджетов/карточек.

---

### Определения и понятия

#### Grid-линия (grid line)

**Grid-линия** — горизонтальная или вертикальная линия, разделяющая строки и колонки сетки. Нумерация начинается с 1.

#### `grid-column` / `grid-row`

**`grid-column`** и **`grid-row`** — свойства grid-элемента для размещения по линиям сетки. Формат: `начало / конец` или `span N`.

#### `span`

**`span`** — ключевое слово в `grid-column` / `grid-row`: элемент занимает указанное количество ячеек. `grid-column: span 2` — на 2 колонки.

#### `grid-template-areas`

**`grid-template-areas`** — свойство grid-контейнера для задания именованных областей. Каждая строка значения — ряд сетки, каждое имя — ячейка.

#### `grid-area`

**`grid-area`** — свойство grid-элемента, назначающее его в именованную область из `grid-template-areas`.

#### Вложенная сетка

**Вложенная сетка** — grid-элемент, который сам является grid-контейнером. Позволяет строить сложные макеты (страница + сетка карточек внутри).

## 4. CSS Grid vs Flexbox

### Когда что использовать

| Задача | Инструмент | Почему |
| ------ | ---------- | ------ |
| Макет страницы (header, sidebar, content, footer) | **Grid** | Двумерная сетка, области |
| Сетка карточек 3×2 | **Grid** | Строки и колонки одновременно |
| Навигация в шапке (логотип + меню) | **Flexbox** | Элементы в один ряд |
| Выравнивание кнопки по центру | **Flexbox** | Одномерное выравнивание |
| Равная высота карточек в ряду | **Grid** | Ячейки одной строки выравниваются |
| Распределение пространства в ряду | **Flexbox** | `justify-content`, `flex: 1` |

### Можно комбинировать

```css
/* Grid — макет страницы */
.layout {
  display: grid;
  grid-template-areas: "header header" "sidebar main" "footer footer";
  grid-template-columns: 200px 1fr;
}

/* Flexbox — навигация внутри шапки */
.header {
  grid-area: header;
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* Grid — карточки внутри main */
.widgets {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
```

### Правило выбора

1. **Одномерная** раскладка (ряд или колонка) → **Flexbox**
2. **Двумерная** раскладка (строки + колонки) → **Grid**
3. Не уверен → начни с Flexbox; если нужны и строки, и колонки — Grid

### Сравнительная таблица

| Свойство | Flexbox | Grid |
| -------- | ------- | ---- |
| Измерения | 1D (ряд или колонка) | 2D (строки + колонки) |
| Контроль | Элементы управляют собой | Контейнер задаёт сетку |
| Выравнивание | `justify-content`, `align-items` | `gap`, `grid-template-*` |
| Области | Нет | `grid-template-areas` |
| Лучше для | Навигация, кнопки, центрирование | Макеты страниц, карточные сетки |

---

### Определения и понятия

#### Flexbox

**Flexbox** — CSS-модуль для одномерной раскладки элементов в ряд или колонку. Изучался ранее в модуле (урок 5).

#### Одномерная раскладка

**Одномерная раскладка** — расположение элементов в одном направлении: либо по горизонтали, либо по вертикали. Область Flexbox.

#### Двумерная раскладка

**Двумерная раскладка** — расположение элементов по строкам и колонкам одновременно. Область CSS Grid.

#### Комбинирование Grid и Flex

**Комбинирование** — использование Grid для общего макета страницы и Flexbox для выравнивания элементов внутри отдельных блоков (шапка, карточка).
