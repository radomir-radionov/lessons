---

## Описание

Сверстай **дашборд** (панель управления) — страницу с боковой навигацией, шапкой, основным контентом из карточек-виджетов и подвалом. Вся раскладка — на **CSS Grid**.

---

## Требования

### 1. Общий макет (grid-template-areas)

```
┌─────────────────────────────────┐
│            header               │
├──────────┬──────────────────────┤
│          │  widget   widget     │
│ sidebar  ├──────────┬───────────┤
│          │  widget  │  widget   │
│          ├──────────┴───────────┤
│          │     widget (wide)   │
├──────────┴──────────────────────┤
│            footer               │
└─────────────────────────────────┘
```

- `grid-template-columns: 240px 1fr`
- `grid-template-rows: auto 1fr auto`
- Области: `header`, `sidebar`, `main`, `footer`

### 2. Шапка (header)

- Название дашборда (текст или логотип)
- Справа — имя пользователя или иконка-заглушка
- Фон: тёмный или акцентный цвет

### 3. Боковая панель (sidebar)

- 4–5 ссылок навигации (текст: «Обзор», «Аналитика», «Настройки» и т.д.)
- Вертикальный список
- Светлый или контрастный фон

### 4. Основной контент (main) — сетка виджетов

Внутри `main` — вложенная grid-сетка `.widgets`:

- **5 виджетов** (карточки с заголовком и числом/текстом)
- Раскладка: 2 виджета в первом ряду, 2 во втором, 1 широкий в третьем
- Используй `grid-template-columns: repeat(2, 1fr)` и `grid-column: span 2` для широкого виджета

Пример виджетов:

| Виджет | Содержимое |
| ------ | ---------- |
| Пользователи | «1 234» |
| Доход | «$5 678» |
| Заказы | «89» |
| Конверсия | «3.2%» |
| График (широкий) | «Статистика за месяц» (текст-заглушка) |

### 5. Подвал (footer)

- Копирайт, год
- Минимальная высота

### 6. Стили

- `gap` между виджетами: 16–24px
- Скругление карточек: `border-radius: 8px`
- Тень или рамка у виджетов
- `min-height: 100vh` у layout

### 7. Адаптивность (бонус, но желательно)

На экранах < 768px:

- Sidebar скрыт (`display: none`)
- Виджеты в 1 колонку
- Header и footer на всю ширину

---

## Пример структуры CSS

```css
.dashboard {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
  gap: 0;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; padding: 24px; }
.footer  { grid-area: footer; }

.widgets {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 24px;
}

.widget--wide {
  grid-column: span 2;
}
```

## Критерии оценки

| Критерий | Балл |
| -------- | ---- |
| Макет через `grid-template-areas` (4 зоны) | обязательно |
| Sidebar фиксированной ширины (~240px) | обязательно |
| Вложенная grid-сетка виджетов в `main` | обязательно |
| 5 виджетов, один широкий (`span 2`) | обязательно |
| Использованы `fr` и `gap` | обязательно |
| `min-height: 100vh` | обязательно |
| Визуально аккуратный дашборд | обязательно |

---

## Бонус (по желанию)

1. **Адаптивность** — media query для мобильного (< 768px)
2. **Цветовая схема** — единые цвета через CSS-переменные или Sass
3. **Hover-эффект** — виджеты слегка поднимаются при наведении (`transform`, `box-shadow`)
4. **Тёмная тема sidebar** — контраст боковой панели и контента

## Частые ошибки — проверь себя

- [ ] `display: grid` на `.dashboard`, не на виджетах верхнего уровня по отдельности
- [ ] `grid-area` у каждого блока совпадает с именем в `grid-template-areas`
- [ ] Вложенная сетка `.widgets` внутри `main`, не снаружи
- [ ] Широкий виджет: `grid-column: span 2`
- [ ] Sidebar имеет фиксированную ширину через `grid-template-columns: 240px 1fr`
- [ ] Не путай Grid (сетка) и Flexbox (выравнивание в ряду) — здесь нужен Grid
