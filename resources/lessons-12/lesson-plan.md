## Краткое содержание блоков

### Блок 1 — Введение (0–8 мин)

- CSS Grid — двумерная сетка (строки + колонки)
- Flexbox — одномерная (ряд или колонка)
- `display: grid` на контейнере

### Блок 2 — Шаблон сетки (8–18 мин)

- `grid-template-columns: 1fr 1fr 1fr`
- `repeat(3, 1fr)`, `gap`
- `grid-template-rows`

### Блок 3 — Линии и области (18–25 мин)

- Нумерация линий с 1
- `grid-column: 1 / 3`, `grid-row`
- `grid-template-areas` для макетов страниц

### Блок 4 — Grid vs Flex (25–32 мин)

- Grid — страничные макеты, карточные сетки
- Flex — навигация, выравнивание в ряду
- Можно комбинировать

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Сетка не появляется | `display: grid` на родителе, не на детях |
| Колонки не равные | Используй `1fr 1fr 1fr`, не `%` |
| Элемент не занимает 2 колонки | `grid-column: span 2` или `1 / 3` |
| `grid-area` не работает | Проверь `grid-template-areas` на контейнере |
| Конфликт с Flexbox | Grid для сетки, Flex для внутреннего выравнивания |
