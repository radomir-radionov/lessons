# Практические задачи — Урок 5

**Время на занятии:** 32–55 мин (~23 минуты)  
**Проект:** папка `flex-practice/` с файлами `index.html` и `style.css`  
**Порядок:** задачи идут по нарастающей сложности — каждая следующая дополняет предыдущую

---

## Задача 1 — «Flex-контейнер» (4 мин)

### Задание

Создай базовую страницу и первый flex-контейнер:

1. Создай папку `flex-practice` с `index.html` и `style.css`
2. В `<body>` добавь блок `<div class="row">` с тремя дочерними `<div class="box">` (текст: «1», «2», «3»)
3. В CSS задай `.row { display: flex; }` и стили для `.box` (фон, padding, минимальная ширина)
4. Убедись, что три блока стоят **в одну строку** (не в колонку)

### Критерии выполнения

- [ ] Подключён внешний файл `style.css`
- [ ] У `.row` есть `display: flex`
- [ ] Три блока `.box` отображаются в ряд
- [ ] У блоков видны фон и отступы

### Подсказка

```css
.row {
  display: flex;
}

.box {
  background-color: #4a90d9;
  color: white;
  padding: 20px;
  min-width: 80px;
  text-align: center;
}
```

## Задача 2 — «Навигация» (5 мин)

### Задание

Сверстай шапку с flex-навигацией:

1. Добавь `<header class="header">` с внутренним `<nav class="nav">`
2. Внутри `nav` — логотип `<a class="nav__logo">Мой сайт</a>` и список из 4 ссылок (`Главная`, `О нас`, `Услуги`, `Контакты`)
3. Сделай `.nav` flex-контейнером: логотип слева, ссылки справа (`justify-content: space-between`)
4. Ссылки в меню тоже в ряд (`display: flex` на `<ul>` или оберни ссылки в `.nav__links`)

### Критерии выполнения

- [ ] Есть семантический `<header>` и `<nav>`
- [ ] Логотип и меню на одной строке
- [ ] Между логотипом и ссылками — свободное пространство (`space-between`)
- [ ] Минимум 4 ссылки в меню
- [ ] Ссылки оформлены (цвет, без подчёркивания или с hover — по желанию)

### Подсказка

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 24px;
  background-color: #1a1a2e;
}

.nav__links {
  display: flex;
  gap: 24px;
  list-style: none;
}
```

## Задача 3 — «Ряд карточек» (6 мин)

### Задание

Добавь секцию с карточками в ряд:

1. После шапки добавь `<section class="cards">` с 3 карточками `.card`
2. В каждой карточке: заголовок `<h3>` и абзац `<p>`
3. Сделай `.cards` flex-контейнером с `gap: 20px` и `flex-wrap: wrap`
4. Карточки одинаковой ширины: `flex: 1` и `min-width: 200px`

### Критерии выполнения

- [ ] Секция содержит 3 карточки
- [ ] Карточки в одном ряду на широком экране
- [ ] Использован `gap` между карточками
- [ ] Использован `flex-wrap: wrap`
- [ ] У карточек есть фон, padding и скругление (`border-radius`)

### Подсказка

```css
.cards {
  display: flex;
  gap: 20px;
  flex-wrap: wrap;
  padding: 24px;
}

.card {
  flex: 1;
  min-width: 200px;
  padding: 20px;
  background-color: #f5f5f5;
  border-radius: 8px;
}
```

## Задача 4 — «Центрирование» (4 мин)

### Задание

Отцентрируй блок по центру страницы:

1. Добавь секцию `<section class="hero">` с блоком `<div class="hero__content">`
2. Внутри — заголовок и кнопка (или ссылка)
3. Задай `.hero` высоту `300px` (или `50vh`)
4. Используй flex для центрирования содержимого по горизонтали и вертикали

### Критерии выполнения

- [ ] Блок `.hero` — flex-контейнер
- [ ] Содержимое по центру по горизонтали (`justify-content: center`)
- [ ] Содержимое по центру по вертикали (`align-items: center`)
- [ ] У секции задана высота
- [ ] Текст внутри выровнен по центру (опционально: `text-align: center` на `.hero__content`)

### Подсказка

```css
.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
  background-color: #e8f4fc;
}
```

## Задача 5 — «Растягивающийся блок» (4 мин)

### Задание

Создай ряд из трёх колонок, где средняя шире:

1. Добавь `<div class="columns">` с тремя блоками `.column`
2. Боковым колонкам задай `flex: 1`
3. Средней колонке задай `flex: 2` (она займёт вдвое больше места)
4. Добавь `gap: 16px` и минимальную высоту колонок

### Критерии выполнения

- [ ] Три колонки в одном flex-ряду
- [ ] Средняя колонка визуально шире боковых
- [ ] Использованы разные значения `flex-grow` (через `flex: 1` и `flex: 2`)
- [ ] Есть `gap` между колонками

### Подсказка

```css
.columns {
  display: flex;
  gap: 16px;
  padding: 24px;
}

.column {
  flex: 1;
  padding: 16px;
  background-color: #ddd;
}

.column--wide {
  flex: 2;
}
```
