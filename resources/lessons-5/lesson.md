## 1. Введение: зачем нужен Flexbox

На предыдущих уроках мы выравнивали элементы с помощью `margin`, `padding` и `display: inline-block`. Это работает для простых случаев, но быстро становится неудобным:

- Как поставить три блока в ряд **одинаковой высоты**?
- Как прижать меню к правому краю, а логотип — к левому?
- Как отцентрировать блок **по вертикали и горизонтали**?

**Flexbox** (Flexible Box Layout) — модуль CSS, созданный специально для **гибких одномерных макетов**: ряд или колонка элементов, которые нужно выровнять и распределить по пространству.

> Flexbox решает задачи **в одном направлении** (ряд или столбец). Для двумерных сеток (строки + столбцы) позже изучим **CSS Grid** (урок 12).

### Аналогия

Представь полку с коробками:

- **Flex-контейнер** — полка
- **Flex-элементы** — коробки на полке
- **`justify-content`** — как коробки распределены **вдоль полки** (слева, по центру, с промежутками)
- **`align-items`** — как коробки выровнены **по высоте** (вверху, по центру, растянуты)
- **`gap`** — фиксированное расстояние между коробками

---

### Определения и понятия

#### Flexbox

**Flexbox** — CSS-модуль для создания гибких макетов. Позволяет выравнивать элементы, распределять свободное пространство и управлять порядком элементов в ряду или колонке.

#### Flex-контейнер (flex container)

**Flex-контейнер** — родительский элемент с `display: flex` или `display: inline-flex`. Только прямые дочерние элементы становятся flex-элементами.

#### Flex-элемент (flex item)

**Flex-элемент** — прямой дочерний элемент flex-контейнера. На него действуют свойства `flex-grow`, `flex-shrink`, `flex-basis`.

#### Одномерный макет

**Одномерный макет** — расположение элементов вдоль **одной оси** (горизонтально или вертикально). Flexbox — одномерный; Grid — двумерный.

## 2. Flex-контейнер и оси

### Включение Flexbox

Чтобы активировать Flexbox, задай родительскому элементу:

```css
.container {
  display: flex;
}
```

Все **прямые дочерние** элементы автоматически становятся flex-элементами и выстраиваются **в ряд** (по умолчанию).

```html
<div class="container">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>
```

```css
.container {
  display: flex;
}

.box {
  padding: 20px;
  background-color: #4a90d9;
  color: white;
}
```

Результат: три блока в одну горизонтальную линию.

### Главная и поперечная оси

У flex-контейнера есть две оси:

| Ось | Английское название | Описание |
| --- | --- | --- |
| **Главная** | main axis | Направление, вдоль которого располагаются flex-элементы |
| **Поперечная** | cross axis | Перпендикулярна главной оси |

По умолчанию главная ось **горизонтальная** (слева направо).

### flex-direction

Свойство `flex-direction` задаёт направление главной оси:

| Значение | Эффект |
| --- | --- |
| `row` | В ряд слева направо (по умолчанию) |
| `row-reverse` | В ряд справа налево |
| `column` | В колонку сверху вниз |
| `column-reverse` | В колонку снизу вверх |

```css
.container {
  display: flex;
  flex-direction: column;
}
```

При `column` главная ось становится **вертикальной**, а поперечная — горизонтальной. Это важно: `justify-content` и `align-items` «меняются местами» по смыслу.

---

### Определения и понятия

#### display: flex

**`display: flex`** — превращает элемент в flex-контейнер. Дочерние элементы выстраиваются в ряд (при `flex-direction: row`).

#### display: inline-flex

**`display: inline-flex`** — flex-контейнер, который сам ведёт себя как строчный элемент (не занимает всю ширину строки). На уроке используем `flex`.

#### Главная ось (main axis)

**Главная ось** — направление, вдоль которого flex-элементы располагаются друг за другом. Задаётся `flex-direction`.

#### Поперечная ось (cross axis)

**Поперечная ось** — ось, перпендикулярная главной. Используется для выравнивания через `align-items`.

#### flex-direction

**`flex-direction`** — свойство flex-контейнера, определяющее направление главной оси: `row`, `column`, `row-reverse`, `column-reverse`.

## 3. Выравнивание элементов

### justify-content — по главной оси

`justify-content` выравнивает flex-элементы **вдоль главной оси** (при `row` — горизонтально):

| Значение | Эффект |
| --- | --- |
| `flex-start` | К началу оси (слева при `row`) |
| `flex-end` | К концу оси (справа при `row`) |
| `center` | По центру |
| `space-between` | Равные промежутки **между** элементами |
| `space-around` | Равные промежутки **вокруг** каждого элемента |
| `space-evenly` | Абсолютно равные промежутки везде |

```css
.nav {
  display: flex;
  justify-content: space-between;
}
```

Типичный паттерн: логотип слева, меню справа.

### align-items — по поперечной оси

`align-items` выравнивает элементы **вдоль поперечной оси** (при `row` — вертикально):

| Значение | Эффект |
| --- | --- |
| `stretch` | Растянуть на всю высоту контейнера (по умолчанию) |
| `flex-start` | К верху |
| `flex-end` | К низу |
| `center` | По центру |
| `baseline` | По базовой линии текста |

```css
.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
}
```

Это самый популярный способ **центрирования** блока по горизонтали и вертикали.

### gap — отступы между элементами

`gap` задаёт расстояние **между** flex-элементами (не снаружи контейнера):

```css
.cards {
  display: flex;
  gap: 20px;
}
```

Можно задать два значения: `gap: 16px 24px` (между рядами и между колонками при `flex-wrap`).

> Раньше для отступов между карточками использовали `margin` на каждом элементе. `gap` — современный и чистый способ.

---

### Определения и понятия

#### justify-content

**`justify-content`** — выравнивание flex-элементов вдоль **главной оси**. Частые значения: `center`, `space-between`, `flex-start`.

#### align-items

**`align-items`** — выравнивание flex-элементов вдоль **поперечной оси**. Частые значения: `center`, `stretch`, `flex-start`.

#### gap

**`gap`** — расстояние между flex-элементами (и grid-элементами). Не добавляет отступ снаружи контейнера.

#### Центрирование через Flexbox

**Центрирование через Flexbox** — комбинация `display: flex`, `justify-content: center`, `align-items: center` на контейнере с заданной высотой.

## 4. Размеры и перенос flex-элементов

### flex-wrap

По умолчанию flex-элементы **не переносятся** — они сжимаются, чтобы поместиться в одну строку. Чтобы разрешить перенос:

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

| Значение | Эффект |
| --- | --- |
| `nowrap` | Все в одну строку (по умолчанию) |
| `wrap` | Перенос на новую строку при нехватке места |
| `wrap-reverse` | Перенос в обратном порядке |

### flex-grow

`flex-grow` определяет, **насколько элемент растёт**, забирая свободное пространство:

```css
.sidebar {
  flex-grow: 1;
}

.main {
  flex-grow: 3;
}
```

Значение `0` (по умолчанию) — элемент не растёт. Значение `1` — элемент забирает долю свободного места.

### flex-shrink

`flex-shrink` определяет, **насколько элемент сжимается** при нехватке места:

- `1` (по умолчанию) — элемент может сжиматься
- `0` — элемент **не сжимается** (сохраняет минимальный размер)

### Сокращённая запись flex

Часто используют свойство `flex` — сокращение для `flex-grow`, `flex-shrink` и `flex-basis`:

```css
.card {
  flex: 1; /* flex-grow: 1; flex-shrink: 1; flex-basis: 0% */
}

.card--wide {
  flex: 2;
}
```

| Запись | Значение |
| --- | --- |
| `flex: 1` | Равномерное распределение пространства |
| `flex: 0 0 200px` | Фиксированная ширина 200px, не растёт и не сжимается |
| `flex: 1 1 200px` | Базовая ширина 200px, может расти и сжиматься |

### Практический паттерн: карточки в ряд

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 250px;
  padding: 20px;
  background-color: #f5f5f5;
  border-radius: 8px;
}
```

Карточки занимают минимум 250px, растут равномерно и переносятся при нехватке места.

---

### Определения и понятия

#### flex-wrap

**`flex-wrap`** — разрешает или запрещает перенос flex-элементов на новую строку/колонку.

#### flex-grow

**`flex-grow`** — коэффициент роста flex-элемента. Чем больше число, тем больше свободного места забирает элемент.

#### flex-shrink

**`flex-shrink`** — коэффициент сжатия flex-элемента при нехватке места. `0` — не сжимается.

#### flex-basis

**`flex-basis`** — начальный размер элемента до распределения свободного места. Аналог `width` для flex-элемента.

#### flex (сокращение)

**`flex`** — сокращённое свойство: `flex-grow flex-shrink flex-basis`. Пример: `flex: 1 1 200px`.
