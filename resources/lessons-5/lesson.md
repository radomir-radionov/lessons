## 1. Введение: зачем нужен Flexbox

Выравнивание через `margin` и `inline-block` быстро усложняется:

- Три блока в ряд **одинаковой высоты**
- Меню справа, логотип слева
- Центрирование блока **по вертикали и горизонтали**

**Flexbox** (Flexible Box Layout) — CSS-модуль для **гибких одномерных макетов**: ряд или колонка элементов с выравниванием и распределением пространства.

| Термин           | Определение                                                          |
| ---------------- | -------------------------------------------------------------------- |
| **Flexbox**      | CSS-модуль для одномерных макетов (ряд или колонка)                  |
| **Flex-контейнер** | Родитель с `display: flex` — только прямые дети становятся flex-элементами |
| **Flex-элемент** | Прямой дочерний элемент flex-контейнера                              |
| **Одномерный макет** | Расположение вдоль одной оси (Flexbox); двумерный — CSS Grid       |

### Аналогия: полка с коробками

| Свойство            | Роль на полке                              |
| ------------------- | ------------------------------------------ |
| Flex-контейнер      | Полка                                      |
| Flex-элементы       | Коробки                                    |
| `justify-content`   | Распределение **вдоль полки**              |
| `align-items`       | Выравнение **по высоте**                   |
| `gap`               | Расстояние между коробками                 |

## 2. Flex-контейнер и оси

### Включение Flexbox

```css
.container {
  display: flex;
}
```

```html
<div class="container">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>
```

Прямые дочерние элементы выстраиваются **в ряд** (по умолчанию).

### Главная и поперечная оси

| Ось              | Англ.       | Описание                                      |
| ---------------- | ----------- | --------------------------------------------- |
| **Главная**      | main axis   | Направление расположения flex-элементов       |
| **Поперечная**   | cross axis  | Перпендикулярна главной                       |

По умолчанию главная ось **горизонтальная** (слева направо).

### flex-direction

| Значение         | Эффект                    |
| ---------------- | ------------------------- |
| `row`            | В ряд слева направо (по умолчанию) |
| `row-reverse`    | В ряд справа налево       |
| `column`         | В колонку сверху вниз     |
| `column-reverse` | В колонку снизу вверх     |

```css
.container {
  display: flex;
  flex-direction: column;
}
```

> При `column` главная ось **вертикальная** — `justify-content` и `align-items` меняют роли по смыслу.

## 3. Выравнивание элементов

### justify-content — по главной оси

| Значение        | Эффект (при `row`)                        |
| --------------- | ----------------------------------------- |
| `flex-start`    | К началу (слева)                          |
| `flex-end`      | К концу (справа)                          |
| `center`        | По центру                                 |
| `space-between` | Равные промежутки **между** элементами    |
| `space-around`  | Равные промежутки **вокруг** каждого      |
| `space-evenly`  | Абсолютно равные промежутки везде         |

```css
.nav {
  display: flex;
  justify-content: space-between;
}
```

Типичный паттерн: логотип слева, меню справа.

### align-items — по поперечной оси

| Значение     | Эффект (при `row`)                    |
| ------------ | ------------------------------------- |
| `stretch`    | Растянуть на всю высоту (по умолчанию) |
| `flex-start` | К верху                               |
| `flex-end`   | К низу                                |
| `center`     | По центру                             |
| `baseline`   | По базовой линии текста               |

### Центрирование блока

```css
.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 300px;
}
```

Нужны **оба** свойства и **заданная высота** контейнера.

### gap — отступы между элементами

```css
.cards {
  display: flex;
  gap: 20px;
}
```

`gap: 16px 24px` — два значения: между рядами и колонками (при `flex-wrap`).

> `gap` чище, чем `margin` на каждой карточке — не добавляет отступ снаружи контейнера.

## 4. Размеры и перенос flex-элементов

### flex-wrap

По умолчанию элементы **не переносятся** — сжимаются в одну строку.

| Значение       | Эффект                              |
| -------------- | ----------------------------------- |
| `nowrap`       | Все в одну строку (по умолчанию)    |
| `wrap`         | Перенос при нехватке места          |
| `wrap-reverse` | Перенос в обратном порядке          |

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

### flex-grow и flex-shrink

```css
.sidebar { flex-grow: 1; }
.main    { flex-grow: 3; }
```

| Свойство      | Значение по умолчанию | Эффект                              |
| ------------- | --------------------- | ----------------------------------- |
| `flex-grow`   | `0`                   | Элемент не растёт                   |
| `flex-shrink` | `1`                   | Элемент сжимается при нехватке места |
| `flex-shrink: 0` | —                  | Элемент **не сжимается**            |

### Сокращённая запись flex

```css
.card       { flex: 1; }           /* grow: 1; shrink: 1; basis: 0% */
.card--wide { flex: 2; }
.fixed      { flex: 0 0 200px; }   /* фикс. 200px, не растёт/сжимается */
.flexible   { flex: 1 1 200px; }   /* база 200px, может расти и сжиматься */
```

### Паттерн: карточки в ряд

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 250px;
  padding: 20px;
  background-color: #f5f5f5;
  border-radius: 8px;
}
```

Карточки: минимум 250px, растут равномерно, переносятся при нехватке места.

### Паттерн: навигация

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
  padding: 16px 24px;
}
```

## 5. Итог урока

### Что мы узнали

1. **Flexbox** — модуль для одномерных макетов (ряд или колонка)
2. **`display: flex`** на **родителе** создаёт flex-контейнер
3. **Главная и поперечная оси** — определяют работу `justify-content` и `align-items`
4. **`justify-content`** — по главной оси; **`align-items`** — по поперечной
5. **`gap`** — отступы между элементами
6. **`flex-wrap`** — перенос на новую строку
7. **`flex-grow` / `flex-shrink` / `flex`** — управление размерами

### Вопросы для самопроверки

1. Какому элементу нужно задать `display: flex` — родителю или дочернему?
2. Чем отличается главная ось от поперечной?
3. Какое свойство центрирует элементы по горизонтали при `flex-direction: row`?
4. Зачем нужен `flex-wrap: wrap`?
5. Что делает `flex: 1`?
6. Чем `gap` лучше, чем `margin` на каждой карточке?
