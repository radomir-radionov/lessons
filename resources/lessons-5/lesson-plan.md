## Краткое содержание блоков

### Блок 1 — Введение (0–5 мин)

- Зачем Flexbox: выравнивание, распределение пространства, адаптивные ряды
- Flexbox vs float (упоминание — float устарел для макетов)
- Ключевые определения: flex-контейнер, flex-элемент, ось

### Блок 2 — Flex-контейнер и оси (5–14 мин)

- `display: flex` на родителе превращает детей в flex-элементы
- Главная ось (`main axis`) и поперечная (`cross axis`)
- `flex-direction`: `row` (по умолчанию), `column`, `row-reverse`, `column-reverse`
- Демо: три блока в ряд и в колонку

### Блок 3 — Выравнивание (14–22 мин)

- `justify-content` — по главной оси: `flex-start`, `center`, `space-between`, `space-around`
- `align-items` — по поперечной: `stretch`, `center`, `flex-start`, `flex-end`
- `gap` — отступы между элементами (современная замена margin между карточками)
- Демо: центрирование блока по горизонтали и вертикали

### Блок 4 — Размеры и перенос (22–32 мин)

- `flex-grow` — элемент забирает свободное место
- `flex-shrink` — элемент сжимается при нехватке места
- `flex-wrap: wrap` — перенос элементов на новую строку
- Краткая запись `flex: 1` (= `flex-grow: 1; flex-shrink: 1; flex-basis: 0`)
- Ученик пробует: один элемент шире остальных через `flex-grow`

## Частые проблемы

| Проблема                                      | Решение                                                                                  |
| --------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Flex не работает                              | Проверить, что `display: flex` на **родителе**, а не на дочерних элементах               |
| Элементы не выравниваются по центру           | Нужны оба: `justify-content: center` и `align-items: center` (и высота у контейнера)     |
| Карточки сжимаются и ломают текст             | Добавить `flex-wrap: wrap` и `min-width` у карточек                                      |
| `gap` не работает в старом браузере           | Для учебного проекта достаточно современного Chrome/Firefox; fallback — `margin`          |
| Меню «ломается» на маленьком экране           | `flex-wrap: wrap` на `.nav` или уменьшить `gap` / `font-size` (media queries — урок 9)   |
| Путаница `justify-content` и `align-items`    | `justify` = главная ось (обычно горизонталь при `row`), `align` = поперечная             |
