4. Сравнить подходы и выбрать фреймворк под задачу

**Результат:** ученик создаёт страницу на Bootstrap Grid и понимает, как тот же блок выглядел бы на Tailwind.

## Краткое содержание блоков

### Блок 1 — Введение (0–7 мин)

- Фреймворк = готовые стили и сетка
- Ускоряет прототипирование, но добавляет зависимость
- CDN для обучения; в продакшене — сборка

### Блок 2 — Подходы (7–15 мин)

- Component: `.btn`, `.card`, `.navbar` (Bootstrap)
- Utility: `.flex`, `.p-4`, `.text-center` (Tailwind)
- Когда что выбирать — таблица в lesson.md

### Блок 3 — Bootstrap (15–28 мин)

- Подключение CSS через CDN
- `.container` → `.row` → `.col-*`
- Брейкпоинты: `col-md-6`, `col-lg-4`
- Готовые компоненты: `.btn`, `.card`

### Блок 4 — Tailwind (28–38 мин)

- Tailwind Play или CDN-скрипт

## Частые проблемы

| Проблема                         | Решение                                                          |
| -------------------------------- | ---------------------------------------------------------------- |
| Стили Bootstrap не применяются   | Проверить `<link>` в `<head>`, порядок подключения CSS           |
| Колонки не встают в ряд          | Нужны и `.row`, и `.col-*` внутри; проверить вложенность         |
| Tailwind CDN не работает         | Использовать официальный Play CDN или скрипт с tailwindcss.com   |
| Конфликт своих стилей и Bootstrap | Свои стили подключать после Bootstrap или использовать BEM      |
| Сетка «ломается» на мобильном    | Добавить классы с префиксами `col-12`, `col-md-6`                |
