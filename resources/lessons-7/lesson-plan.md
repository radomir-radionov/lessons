## Краткое содержание блоков

### Блок 1 — Фоновые изображения (0–10 мин)

- `background-image: url(...)` — картинка как фон
- `background-size: cover` / `contain` — как картинка заполняет область
- `background-position: center` — позиция фона
- `background-repeat: no-repeat`
- Hero-секция: текст поверх фоновой картинки

### Блок 2 — object-fit (10–16 мин)

- Проблема: `<img>` искажается при фиксированных размерах
- `object-fit: cover` — заполнить блок, обрезая лишнее
- `object-fit: contain` — вписать целиком
- `border-radius: 50%` + `object-fit: cover` = круглый аватар

### Блок 3 — transform (16–24 мин)

- `transform` не влияет на поток документа (в отличие от `margin`)
- `rotate(45deg)` — поворот
- `scale(1.2)` — увеличение
- `translateX(-50%)` — сдвиг (центрирование)
- Комбинация: `transform: rotate(45deg) scale(1.1)`

### Блок 4 — calc() (24–28 мин)

- `calc()` — вычисления в CSS: `calc(100% - 32px)`
- Пробелы вокруг `+` и `-` обязательны
- Паттерн: контейнер минус padding/margin

### Блок 5 — Многослойные фоны (28–32 мин)

- Градиент поверх картинки для затемнения (overlay)

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Фоновая картинка не видна | Проверить путь в `url()`, задать `height` контейнеру |
| Картинка повторяется | `background-repeat: no-repeat` |
| Аватар не круглый | `border-radius: 50%` + одинаковые `width` и `height` |
| `calc()` не работает | Пробелы: `calc(100% - 20px)`, не `calc(100%-20px)` |
| Transform «обрезается» | У родителя может быть `overflow: hidden` |
| Текст на фоне не читается | Добавить полупрозрачный градиент поверх картинки |
