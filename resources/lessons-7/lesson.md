## 1. Фоновые изображения (background)

До сих пор мы использовали `<img>` для картинок. Но часто изображение нужно как **фон** блока — например, hero-секция на всю ширину с текстом поверх.

Для этого используются свойства семейства **`background-*`**.

### background-image

```css
.hero {
  background-image: url("images/hero.jpg");
}
```

Путь в `url()` — как в `src` у `<img>`: относительный или абсолютный URL.

### background-size

Определяет, как картинка заполняет область:

| Значение | Эффект |
| --- | --- |
| `cover` | Заполнить всю область, обрезая лишнее (сохраняет пропорции) |
| `contain` | Вписать целиком, могут остаться пустые поля |
| `100% 100%` | Растянуть на всю область (может исказить) |
| `200px 150px` | Конкретные размеры |

```css
.hero {
  background-size: cover;
}
```

`cover` — самый популярный вариант для hero-секций.

### background-position

Позиция фонового изображения:

```css
.hero {
  background-position: center;
}
```

Частые значения: `center`, `top`, `bottom`, `left`, `right`, или пиксели/проценты (`50% 30%`).

### background-repeat

```css
.hero {
  background-repeat: no-repeat;
}
```

| Значение | Эффект |
| --- | --- |
| `repeat` | Повторять (по умолчанию) |
| `no-repeat` | Не повторять |
| `repeat-x` | Только по горизонтали |
| `repeat-y` | Только по вертикали |

### Сокращённая запись background

```css
.hero {
  background: #333 url("hero.jpg") center/cover no-repeat;
}
```

Порядок: цвет → картинка → позиция/размер → повтор.

### Hero-секция: полный пример

```css
.hero {
  height: 400px;
  background-image: url("https://images.unsplash.com/photo-1506905925346-21bda4d32df4?w=1200");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  display: flex;
  justify-content: center;
  align-items: center;
  color: white;
  text-shadow: 0 2px 8px rgba(0, 0, 0, 0.6);
}
```

> Для фоновой картинки **не нужен** `alt` — она декоративная. Если картинка несёт смысл, добавь скрытый текст или используй `<img>` с `alt`.

---

### Определения и понятия

#### background-image

**`background-image`** — CSS-свойство для установки фонового изображения элемента.

#### background-size

**`background-size`** — размер фонового изображения. `cover` — заполнить область с обрезкой; `contain` — вписать целиком.

#### background-position

**`background-position`** — позиция фонового изображения внутри элемента.

#### background-repeat

**`background-repeat`** — повторение фонового изображения.

#### Hero-секция

**Hero-секция** — крупный баннер в верхней части страницы с заголовком и призывом к действию. Часто с фоновым изображением.

## 2. Работа с изображениями: object-fit

Когда `<img>` помещают в блок фиксированного размера, картинка может **исказиться** (растянуться или сжаться).

**`object-fit`** управляет тем, как содержимое `<img>` (или `<video>`) вписывается в заданные размеры:

```css
.avatar {
  width: 120px;
  height: 120px;
  object-fit: cover;
  border-radius: 50%;
}
```

| Значение | Эффект |
| --- | --- |
| `fill` | Растянуть на весь блок (по умолчанию, может исказить) |
| `cover` | Заполнить блок, обрезая лишнее (сохраняет пропорции) |
| `contain` | Вписать целиком, могут быть пустые поля |
| `none` | Оригинальный размер |
| `scale-down` | Как `none` или `contain` — что меньше |

### object-position

Управляет **какая часть** картинки видна при обрезке:

```css
.avatar {
  object-fit: cover;
  object-position: top center;
}
```

### Круглый аватар

```css
.profile__avatar {
  width: 120px;
  height: 120px;
  border-radius: 50%;
  object-fit: cover;
  border: 3px solid white;
}
```

Ключ: одинаковые `width` и `height` + `border-radius: 50%` + `object-fit: cover`.

---

### Определения и понятия

#### object-fit

**`object-fit`** — способ вписывания содержимого `<img>`/`<video>` в заданные размеры блока.

#### object-position

**`object-position`** — какая часть изображения видна при обрезке (`cover`/`contain`).

#### cover (object-fit)

**`object-fit: cover`** — изображение заполняет блок полностью, обрезая излишки. Пропорции сохраняются.

#### contain (object-fit)

**`object-fit: contain`** — изображение вписывается в блок целиком, без обрезки.

## 3. Трансформация: transform

Свойство **`transform`** изменяет внешний вид элемента: поворачивает, масштабирует, сдвигает — **без влияния на поток документа** (соседние элементы не сдвигаются).

### rotate — поворот

```css
.icon:hover {
  transform: rotate(90deg);
}
```

Положительные градусы — по часовой стрелке.

### scale — масштаб

```css
.card:hover {
  transform: scale(1.05);
}
```

`scale(1)` — оригинальный размер. `scale(1.5)` — в 1.5 раза больше. `scale(0.8)` — меньше.

### translate — сдвиг

```css
.badge {
  transform: translateX(-50%);
}

.centered {
  transform: translate(-50%, -50%);
}
```

`translateX` — по горизонтали, `translateY` — по вертикали.

### Комбинация трансформаций

```css
.icon:hover {
  transform: rotate(45deg) scale(1.1);
}
```

Несколько функций через пробел в одном `transform`.

### Центрирование через transform

Классический приём (до Flexbox):

```css
.modal {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

Сдвигает элемент на половину своей ширины/высоты назад — идеальное центрирование.

---

### Определения и понятия

#### transform

**`transform`** — CSS-свойство для визуальной трансформации элемента (поворот, масштаб, сдвиг).

#### rotate()

**`rotate(угол)`** — поворот элемента на заданное количество градусов.

#### scale()

**`scale(коэффициент)`** — масштабирование элемента. `1` — без изменений.

#### translate()

**`translate(x, y)`** — сдвиг элемента по осям X и Y.

#### transform-origin

**`transform-origin`** — точка, относительно которой происходит трансформация. По умолчанию — центр элемента.

## 4. Вычисляемые размеры: calc()

Функция **`calc()`** позволяет выполнять **математические вычисления** прямо в CSS:

```css
.content {
  width: calc(100% - 200px);
}

.sidebar {
  width: 200px;
}
```

### Правила calc()

1. **Пробелы обязательны** вокруг `+` и `-`: `calc(100% - 20px)`, не `calc(100%-20px)`
2. Можно смешивать единицы: `%`, `px`, `em`, `vw`
3. `* ` и `/` — пробелы не обязательны, но рекомендуются

### Типичные применения

```css
/* Контейнер минус боковые отступы */
.wrapper {
  width: calc(100% - 40px);
  margin: 0 20px;
}

/* Две колонки с gap */
.col {
  width: calc(50% - 10px);
}

/* Высота минус шапка */
.main {
  min-height: calc(100vh - 60px);
}
```

`100vh` — 100% высоты видимой области экрана (viewport height).

---

### Определения и понятия

#### calc()

**`calc()`** — CSS-функция для математических вычислений с разными единицами измерения.

#### vh (viewport height)

**`vh`** — единица измерения: 1vh = 1% высоты окна браузера. `100vh` — вся видимая высота.

#### vw (viewport width)

**`vw`** — единица измерения: 1vw = 1% ширины окна браузера.

## 5. Многослойные фоны

CSS позволяет задать **несколько фоновых изображений** одному элементу — через запятую:

```css
.banner {
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.7)),
    url("photo.jpg");
  background-size: cover;
  background-position: center;
}
```

### Порядок слоёв

**Первый** в списке — **верхний** слой (ближе к пользователю). Градиент поверх картинки затемняет её — текст становится читаемым.

### linear-gradient

```css
background-image: linear-gradient(
  to right,
  rgba(0, 0, 0, 0.8),
  rgba(0, 0, 0, 0.2)
);
```

| Параметр | Значение |
| --- | --- |
| Направление | `to right`, `to bottom`, `45deg` |
| Цвета | `rgba(0,0,0,0.5)`, `#00000080` |

### Overlay (оверлей)

**Overlay** — полупрозрачный слой поверх изображения для улучшения читаемости текста. Реализуется через градиент как верхний фоновый слой.

```css
.promo {
  background-image:
    linear-gradient(to bottom, transparent, rgba(0, 0, 0, 0.8)),
    url("promo.jpg");
  background-size: cover;
  min-height: 400px;
}
```

---

### Определения и понятия

#### Многослойный фон

**Многослойный фон** — несколько `background-image`, разделённых запятой. Первый — верхний слой.

#### linear-gradient

**`linear-gradient`** — CSS-функция для создания плавного перехода между цветами по прямой линии.

#### Overlay (оверлей)

**Overlay** — полупрозрачный слой поверх изображения. В CSS — через градиент как верхний фон.

#### rgba() в градиентах

**`rgba()`** в градиентах создаёт плавный переход от прозрачного к непрозрачному, затемняя фон.
