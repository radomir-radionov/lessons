# Практические задачи — Урок 9

**Время на занятии:** 32–55 мин (~23 минуты)  
**Папка:** `adaptive-layout/`  
**Файлы:** `index.html`, `style.css`  
**Порядок:** задачи идут по нарастающей сложности — каждая следующая дополняет предыдущую

---

## Задача 1 — «Каркас и контейнер» (5 мин)

### Задание

Создай папку `adaptive-layout/` с файлами `index.html` и `style.css`.

1. В HTML — семантическая структура: `header`, `main`, `footer`
2. Внутри `main` — секция с классом `container`
3. В CSS — стиль `.container`:
   - `max-width: 1200px`
   - `margin: 0 auto`
   - `padding: 0 16px`

### Критерии выполнения

- [ ] Папка `adaptive-layout/` с `index.html` и `style.css`
- [ ] CSS подключён через `<link rel="stylesheet" href="style.css">`
- [ ] Контейнер не растягивается шире 1200px на большом экране
- [ ] Контейнер центрирован по горизонтали

### Подсказка

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
```

## Задача 2 — «Три колонки» (5 мин)

### Задание

Внутри `.container` добавь блок `.columns` с тремя колонками `.column`:

1. Каждая колонка — `div` с заголовком `h3` и абзацем `p`
2. Раскладка через Flexbox: `.columns { display: flex; gap: 24px; }`
3. Каждая колонка: `flex: 1` (равная ширина)

### Критерии выполнения

- [ ] Три колонки с разным содержимым
- [ ] Колонки стоят в один ряд на широком экране
- [ ] Между колонками есть отступ (`gap`)
- [ ] Колонки примерно одинаковой ширины

### Подсказка

```css
.columns {
  display: flex;
  gap: 24px;
}

.column {
  flex: 1;
}
```

## Задача 3 — «Относительные единицы» (5 мин)

### Задание

Добавь в `header` блок `.hero` с заголовком и подзаголовком:

1. `.hero` — `width: 100%`, `padding: 8vh 16px`, фоновый цвет
2. Заголовок `h1` — `font-size: 5vw` (только для демонстрации)
3. Подзаголовок — `width: 80%`, `max-width: 600px`

### Критерии выполнения

- [ ] Hero-блок занимает всю ширину
- [ ] Вертикальные отступы заданы через `vh`
- [ ] Подзаголовок не шире 600px
- [ ] При изменении ширины окна hero масштабируется

### Подсказка

```css
.hero {
  width: 100%;
  padding: 8vh 16px;
  background-color: #e8f4fc;
  text-align: center;
}

.hero__subtitle {
  width: 80%;
  max-width: 600px;
  margin: 0 auto;
}
```

## Задача 4 — «Колонки в одну на мобильном» (5 мин)

### Задание

Добавь media query, чтобы на экранах ≤ 768px колонки вставали в столбик:

1. `@media (max-width: 768px) { ... }`
2. `.columns { flex-direction: column; }`
3. Добавь `padding` колонкам на мобильном для читаемости

### Критерии выполнения

- [ ] На широком экране — 3 колонки в ряд
- [ ] На экране ≤ 768px — колонки друг под другом
- [ ] Нет горизонтальной прокрутки на мобильном
- [ ] Проверено в DevTools (режим устройства)

### Подсказка

```css
@media (max-width: 768px) {
  .columns {
    flex-direction: column;
  }

  .column {
    padding: 16px 0;
  }
}
```

## Задача 5 — «Адаптивная шапка» (5 мин)

### Задание

Стилизуй `header`:

1. Внутри — логотип (текст) и навигация из 3 ссылок
2. На десктопе — логотип слева, меню справа (`display: flex; justify-content: space-between`)
3. На мобильном (≤ 768px) — логотип и меню друг под другом, ссылки по центру

### Критерии выполнения

- [ ] Шапка с логотипом и 3 ссылками
- [ ] На десктопе — горизонтальная раскладка
- [ ] На мобильном — вертикальная раскладка
- [ ] Один media query управляет переключением

### Подсказка

```css
.header__inner {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

@media (max-width: 768px) {
  .header__inner {
    flex-direction: column;
    gap: 16px;
  }
}
```
