# Домашнее задание — Урок 9

**Задание:** «Адаптивный лендинг»  
**Время:** ~40–50 минут  
**Папка:** возьми свой мини-лендинг из [урока 3](../lessons-3/homework.md) или создай новый проект `adaptive-landing/`

---

## Описание

Адаптируй одностраничный лендинг под разные размеры экрана. Используй навыки урока: `max-width`, относительные единицы, media queries.

---

## Требования

### 1. Контейнер

- Класс `.container` с `max-width: 1200px`, `margin: 0 auto`, `padding: 0 16px`
- Все основные секции обёрнуты в контейнер

### 2. Hero-блок

- Занимает всю ширину (`width: 100%`)
- Вертикальные отступы через `vh` (например, `padding: 10vh 16px`)
- Заголовок и подзаголовок читаемы на любом экране

### 3. Секция карточек (преимущества)

- На десктопе (ширина > 768px): **3 карточки в ряд** (Flexbox или Grid)
- На мобильном (≤ 768px): **карточки в столбик**
- Между карточками — `gap: 24px`

### 4. Шапка

- На десктопе: логотип слева, меню справа
- На мобильном: логотип и меню друг под другом

### 5. Media queries

- Минимум **2 media query** с `@media (max-width: 768px)`
- Один — для колонок/карточек, второй — для шапки или типографики

### 6. Проверка

- Открой DevTools → режим устройства
- Проверь ширины: 375px (iPhone), 768px (планшет), 1200px+ (десктоп)
- Нет горизонтальной прокрутки на мобильном

---

## Пример структуры CSS

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}

.features__grid {
  display: flex;
  gap: 24px;
}

.feature-card {
  flex: 1;
}

@media (max-width: 768px) {
  .features__grid {
    flex-direction: column;
  }

  .header__inner {
    flex-direction: column;
    text-align: center;
  }
}
```

---

## Критерии оценки

| Критерий | Балл |
| -------- | ---- |
| Контейнер с `max-width` и центрированием | обязательно |
| Карточки в 3 колонки на десктопе | обязательно |
| Карточки в 1 колонку на мобильном (≤ 768px) | обязательно |
| Адаптивная шапка | обязательно |
| Минимум 2 media query | обязательно |
| Нет горизонтальной прокрутки на 375px | обязательно |
| Использованы относительные единицы (`%`, `vh`) хотя бы в одном месте | обязательно |

## Бонус (по желанию)

1. **Второй брейкпоинт** — добавь `@media (max-width: 480px)` для уменьшения шрифтов
2. **Адаптивные изображения** — `img { max-width: 100%; height: auto; }`
3. **Скрытие элемента** — на мобильном скрой декоративный блок через `display: none`

## Как сдать

1. Убедись, что проект открывается в браузере
2. Сделай скриншоты на 375px и 1200px (DevTools)
3. Покажи результат на следующем занятии или отправь папку преподавателю

---

## Частые ошибки — проверь себя

- [ ] Media query написан с единицами: `768px`, не `768`
- [ ] `max-width` у контейнера, а не фиксированный `width: 1200px`
- [ ] На мобильном нет горизонтального скролла
- [ ] Flexbox-колонки переключаются через `flex-direction: column`
- [ ] Проверил в DevTools, а не только сузил окно браузера на десктопе
