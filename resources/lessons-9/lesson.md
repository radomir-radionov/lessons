## 1. Введение: адаптивная и резиновая вёрстка

### Зачем сайту быть адаптивным

Пользователи заходят с телефонов, планшетов и мониторов. Если страница свёрстана только под 1920px, на телефоне будет мелкий текст, горизонтальная прокрутка и элементы за краем экрана.

**Адаптивная вёрстка** — макет подстраивается под размер экрана: элементы меняют расположение, размеры и отступы.

### Резиновая vs адаптивная

| Подход | Суть | Пример |
| ------ | ---- | ------ |
| **Резиновая** (fluid) | Элементы плавно масштабируются (`%`, `vw`) | Колонка `width: 33%` — всегда треть экрана |
| **Адаптивная** (adaptive) | При определённой ширине раскладка **переключается** | 3 колонки → 1 колонка при 768px |

На практике оба подхода **сочетаются**: резиновые размеры + media queries.

### Аналогия

| Часть | Роль |
| ----- | ---- |
| Фиксированная (`px`) | Полка строго 120 см — книги не влезают |
| Резиновая (`%`) | Полки растягиваются, но всегда 3 ряда |
| Адаптивная (media queries) | На узкой стене 3 ряда становятся 1 столбиком |

### Ключевые понятия

| Термин | Определение |
| ------ | ----------- |
| **Адаптивная вёрстка** | Макет подстраивается под размер экрана: относительные единицы + media queries |
| **Резиновая вёрстка** | Размеры в `%`, `vw`, `em` — плавно меняются без жёстких точек переключения |
| **Viewport** | Видимая область страницы в окне браузера (ширина окна, не монитора) |
| **Breakpoint** | Ширина экрана, при которой меняется раскладка |

## 2. Относительные единицы измерения

### Сравнение единиц

| Единица | От чего считается | Когда использовать |
| ------- | ----------------- | ------------------ |
| `px` | Фиксированный размер | Границы, мелкие отступы, иконки |
| `%` | Родительский элемент | Ширина колонок, отступы внутри контейнера |
| `vw` | 1% ширины viewport | Полноширинные блоки (`100vw`) |
| `vh` | 1% высоты viewport | Полноэкранные секции (`min-height: 100vh`) |

### Пиксели — `px`

**Пиксель (`px`)** — абсолютная единица. `font-size: 16px` всегда 16 пикселей.

### Проценты — `%`

**Процент (`%`)** считается от **родительского элемента**:

```css
.parent {
  width: 800px;
}

.child {
  width: 50%; /* = 400px */
}
```

> Если у родителя нет явной ширины, процент может вести себя непредсказуемо.

### Viewport — `vw` / `vh`

```css
.hero {
  width: 100vw;   /* вся ширина окна */
  height: 50vh;   /* половина высоты окна */
  padding: 8vh 0;
}
```

> **Важно:** не используй `vw` для размера шрифта — на узких экранах текст станет слишком мелким. Для шрифтов лучше `rem` или `px`.

## 3. max-width и контейнер

### Проблема «растянутого» контента

На мониторе 2560px строки текста становятся слишком длинными. Нужно **ограничить** ширину и **центрировать** блок.

### Паттерн `.container`

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
```

| Свойство | Зачем |
| -------- | ----- |
| `max-width: 1200px` | Контент не шире 1200px |
| `margin: 0 auto` | Центрирование по горизонтали |
| `padding: 0 16px` | Отступы от краёв на узких экранах |

### `width` vs `max-width`

```css
/* Фиксированная — на узком экране вылезет за край */
.box-fixed {
  width: 1200px;
}

/* Максимальная — сжимается на узком экране */
.box-fluid {
  max-width: 1200px;
  width: 100%;
}
```

**Правило:** для адаптивных контейнеров используй `max-width`, а не фиксированный `width`.

### HTML-структура

```html
<header>
  <div class="container">
    <h1>Логотип</h1>
    <nav>...</nav>
  </div>
</header>

<main>
  <div class="container">
    <section>...</section>
  </div>
</main>
```

Секции (`header`, `main`) могут иметь фон на всю ширину, а контент внутри `.container` — ограничен.

## 4. Media queries

### Что такое media query

**Media query** — CSS-правило, которое применяет стили **только при определённых условиях** (чаще всего — при определённой ширине экрана).

```css
/* Базовые стили — для всех экранов */
.columns {
  display: flex;
  gap: 24px;
}

/* Стили только для узких экранов */
@media (max-width: 768px) {
  .columns {
    flex-direction: column;
  }
}
```

### Синтаксис

```css
@media (условие) {
  /* CSS-правила */
}
```

| Условие | Когда срабатывает |
| ------- | ----------------- |
| `(max-width: 768px)` | Ширина экрана **≤** 768px |
| `(min-width: 769px)` | Ширина экрана **≥** 769px |
| `(min-width: 768px) and (max-width: 1024px)` | От 768px до 1024px |

### Desktop-first

Базовые стили — для широкого экрана, в media query **переопределяем** для узкого:

```css
/* Десктоп: 3 колонки */
.cards {
  display: flex;
}

.card {
  flex: 1;
}

/* Мобильный: 1 колонка */
@media (max-width: 768px) {
  .cards {
    flex-direction: column;
  }
}
```

### Пример: адаптивная шапка

```css
.header__inner {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

@media (max-width: 768px) {
  .header__inner {
    flex-direction: column;
    gap: 16px;
    text-align: center;
  }
}
```

### Как проверять

| Шаг | Действие |
| --- | -------- |
| 1 | Открой страницу в браузере |
| 2 | `F12` → иконка «Toggle device toolbar» (`Cmd+Shift+M`) |
| 3 | Выбери устройство или задай ширину вручную |
| 4 | Убедись, что раскладка меняется при 768px |

### Частые ошибки

| Проблема | Решение |
| -------- | ------- |
| Контент растягивается на весь экран | Добавить `.container` с `max-width` |
| Колонки не схлопываются | Проверить media query и селектор |
| Горизонтальная прокрутка | Убрать фиксированную ширину |
| Media query не срабатывает | Проверить скобки, единицы (`768px`, не `768`) |

## 5. Итог урока

### Что мы узнали

1. **Адаптивная вёрстка** подстраивает макет под размер экрана
2. **Относительные единицы** (`%`, `vw`, `vh`) делают размеры гибкими
3. **`max-width` + `margin: 0 auto`** — стандартный паттерн контейнера
4. **Media queries** переключают раскладку при определённой ширине
5. **Desktop-first** — базовые стили для широкого экрана, переопределение для узкого
