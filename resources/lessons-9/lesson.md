## 1. Введение: адаптивная и резиновая вёрстка

### Зачем сайту быть адаптивным

Пользователи заходят на сайты с телефонов, планшетов, ноутбуков и широких мониторов. Если страница свёрстана только под один размер экрана (например, 1920px), на телефоне она будет неудобной: мелкий текст, горизонтальная прокрутка, элементы вылезают за край.

**Адаптивная вёрстка** — подход, при котором макет подстраивается под размер экрана. Элементы меняют расположение, размеры и отступы в зависимости от ширины окна браузера.

### Резиновая vs адаптивная

| Подход | Суть | Пример |
| ------ | ---- | ------ |
| **Резиновая** (fluid) | Элементы плавно масштабируются (%, vw) | Колонка `width: 33%` всегда треть экрана |
| **Адаптивная** (adaptive) | При определённой ширине раскладка **переключается** | 3 колонки → 1 колонка при 768px |

На практике оба подхода **сочетаются**: резиновые размеры + media queries для смены раскладки.

### Аналогия

Представь книжную полку:

- **Фиксированная** (`px`) — полка строго 120 см, книги не влезают
- **Резиновая** (`%`) — полки растягиваются, но всегда 3 ряда
- **Адаптивная** (media queries) — на узкой стене 3 ряда становятся 1 столбиком

---

### Определения и понятия

#### Адаптивная вёрстка (responsive layout)

**Адаптивная вёрстка** — техника создания сайтов, которые корректно отображаются на экранах разной ширины. Достигается комбинацией относительных единиц, гибких контейнеров и media queries.

#### Резиновая вёрстка (fluid layout)

**Резиновая вёрстка** — подход, при котором размеры элементов заданы в относительных единицах (`%`, `vw`, `em`) и плавно меняются при изменении размера окна, без жёстких точек переключения.

#### Viewport (область просмотра)

**Viewport** — видимая область страницы в окне браузера. Ширина viewport — это ширина окна браузера (не ширина монитора). На мобильных без `<meta name="viewport">` браузер может «сжимать» страницу — об этом подробнее на [уроке 10](lesson.md).

#### Breakpoint (точка перелома)

**Breakpoint** — ширина экрана, при которой меняется раскладка. Например, при 768px три колонки становятся одной. Конкретные брейкпоинты разберём на следующем уроке.

## 2. Относительные единицы измерения

### Пиксели — `px`

**Пиксель (`px`)** — абсолютная единица. `font-size: 16px` всегда 16 пикселей, независимо от родителя и экрана.

Подходит для: границ (`border: 1px`), мелких отступов, фиксированных размеров иконок.

### Проценты — `%`

**Процент (`%`)** — относительная единица. Значение считается от **родительского элемента**:

```css
.parent {
  width: 800px;
}

.child {
  width: 50%; /* = 400px */
}
```

Если у родителя нет явной ширины, процент может вести себя непредсказуемо. Убедись, что родитель имеет заданную ширину.

Подходит для: ширины колонок, отступов внутри контейнера.

### Viewport Width / Height — `vw` / `vh`

**`vw`** (viewport width) — 1% ширины окна браузера.  
**`vh`** (viewport height) — 1% высоты окна браузера.

```css
.hero {
  width: 100vw;   /* вся ширина окна */
  height: 50vh;   /* половина высоты окна */
  padding: 8vh 0; /* вертикальные отступы — 8% высоты окна */
}
```

| Единица | От чего считается | Пример |
| ------- | ----------------- | ------ |
| `px` | Фиксированный размер | `border: 2px` |
| `%` | Родительский элемент | `width: 50%` |
| `vw` | Ширина viewport | `width: 100vw` |
| `vh` | Высота viewport | `min-height: 100vh` |

> **Важно:** не используй `vw` для размера шрифта на первых порах — на узких экранах текст станет слишком мелким. Для шрифтов лучше `rem` или `px`.

---

### Определения и понятия

#### Абсолютная единица

**Абсолютная единица** (`px`) — не зависит от других элементов. Один пиксель на экране — одна точка.

#### Относительная единица

**Относительная единица** (`%`, `vw`, `vh`, `em`, `rem`) — вычисляется на основе другого значения (родителя, viewport, корневого шрифта).

#### `vw` (viewport width)

**`vw`** — 1/100 ширины области просмотра. `100vw` = полная ширина окна.

#### `vh` (viewport height)

**`vh`** — 1/100 высоты области просмотра. `100vh` = полная высота окна (полноэкранный блок).

## 3. max-width и контейнер

### Проблема «растянутого» контента

Если контент занимает 100% ширины на мониторе 2560px, строки текста становятся слишком длинными — читать неудобно. Нужно **ограничить** максимальную ширину и **центрировать** блок.

### Паттерн `.container`

Стандартный приём в вёрстке — обёртка-контейнер:

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
```

| Свойство | Зачем |
| -------- | ----- |
| `max-width: 1200px` | Контент не шире 1200px |
| `margin: 0 auto` | Центрирование по горизонтали |
| `padding: 0 16px` | Отступы от краёв на узких экранах |

### `width` vs `max-width`

```css
/* Фиксированная ширина — на узком экране вылезет за край */
.box-fixed {
  width: 1200px;
}

/* Максимальная ширина — сжимается на узком экране */
.box-fluid {
  max-width: 1200px;
  width: 100%;
}
```

**Правило:** для адаптивных контейнеров используй `max-width`, а не фиксированный `width`.

### HTML-структура

```html
<header>
  <div class="container">
    <h1>Логотип</h1>
    <nav>...</nav>
  </div>
</header>

<main>
  <div class="container">
    <section>...</section>
  </div>
</main>
```

Секции (`header`, `main`) могут иметь фон на всю ширину, а контент внутри `.container` — ограничен.

---

### Определения и понятия

#### `max-width`

**`max-width`** — CSS-свойство, задающее **максимальную** ширину элемента. Элемент может быть узче, но не шире указанного значения.

#### `margin: 0 auto`

**`margin: 0 auto`** — сокращённая запись: верхний и нижний отступ 0, левый и правый — `auto`. Браузер делит свободное пространство поровну, **центрируя** блочный элемент с заданной шириной.

#### Контейнер (container)

**Контейнер** — обёртка с ограниченной шириной, внутри которой располагается основной контент страницы. Стандартная ширина: 1140px, 1200px или 1280px.

## 4. Media queries

### Что такое media query

**Media query** — CSS-правило, которое применяет стили **только при определённых условиях** (чаще всего — при определённой ширине экрана).

```css
/* Базовые стили — для всех экранов */
.columns {
  display: flex;
  gap: 24px;
}

/* Стили только для узких экранов */
@media (max-width: 768px) {
  .columns {
    flex-direction: column;
  }
}
```

### Синтаксис

```css
@media (условие) {
  /* CSS-правила */
}
```

Частые условия:

| Условие | Когда срабатывает |
| ------- | ----------------- |
| `(max-width: 768px)` | Ширина экрана **≤** 768px |
| `(min-width: 769px)` | Ширина экрана **≥** 769px |
| `(min-width: 768px) and (max-width: 1024px)` | От 768px до 1024px |

### Desktop-first на этом уроке

Сегодня мы пишем **базовые стили для широкого экрана**, а в media query **переопределяем** для узкого:

```css
/* Десктоп: 3 колонки */
.cards {
  display: flex;
}

.card {
  flex: 1;
}

/* Мобильный: 1 колонка */
@media (max-width: 768px) {
  .cards {
    flex-direction: column;
  }
}
```

Подход **mobile-first** (сначала мобильный, потом десктоп) — на [уроке 10](../lessons-10/lesson.md).

### Практический пример: адаптивная шапка

```css
.header__inner {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

@media (max-width: 768px) {
  .header__inner {
    flex-direction: column;
    gap: 16px;
    text-align: center;
  }
}
```

### Как проверять

1. Открой страницу в браузере
2. Нажми `F12` → иконка «Toggle device toolbar» (или `Cmd+Shift+M`)
3. Выбери устройство (iPhone, iPad) или задай ширину вручную
4. Убедись, что раскладка меняется при 768px

---

### Определения и понятия

#### Media query

**Media query** — CSS-конструкция `@media`, позволяющая применять стили в зависимости от характеристик устройства (ширина, высота, ориентация, тип экрана).

#### `@media (max-width: ...)`

**`max-width`** в media query — условие «если ширина viewport **не больше** указанного значения». Стили внутри блока применяются на экранах узких и равных заданной ширине.

#### Desktop-first

**Desktop-first** — подход, при котором базовые стили пишутся для широкого экрана, а media queries с `max-width` адаптируют макет для узких экранов.

#### Fluid layout (резиновый макет)

**Fluid layout** — макет, элементы которого используют относительные размеры и плавно подстраиваются под ширину экрана без жёстких скачков.
