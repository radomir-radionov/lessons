## Цели урока

К концу занятия ученик сможет:

1. Использовать относительные единицы (`%`, `vw`, `vh`) для гибких размеров
2. Ограничивать ширину контента через `max-width` и центрировать контейнер
3. Писать media queries для изменения раскладки на разных экранах

**Результат:** ученик создаёт адаптивную страницу с контейнером `max-width` и колонками, которые схлопываются на узком экране.

## Краткое содержание блоков

### Блок 1 — Введение (0–5 мин)

- Почему сайт должен работать на телефоне, планшете и десктопе
- Резиновая vs адаптивная вёрстка
- Ключевые определения: адаптивность, viewport, breakpoint

### Блок 2 — Относительные единицы (5–15 мин)

- `px` — фиксированные пиксели
- `%` — относительно родителя
- `vw` / `vh` — относительно окна браузера
- Когда что использовать

### Блок 3 — max-width и контейнер (15–22 мин)

- Паттерн `.container { max-width: 1200px; margin: 0 auto; padding: 0 16px; }`
- Разница `width` vs `max-width`
- Демо: сужение окна браузера

### Блок 4 — Media queries (22–32 мин)

- Синтаксис `@media (max-width: 768px) { ... }`
- Desktop-first подход (подробнее mobile-first — урок 10)
- Переключение `flex-direction: column` или `grid-template-columns: 1fr`

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Контент растягивается на весь экран | Добавить `.container` с `max-width` |
| Колонки не схлопываются | Проверить media query и селектор |
| Горизонтальная прокрутка | `overflow-x: hidden` на `body` или убрать фиксированную ширину |
| `vw` даёт слишком мелкий текст | Не использовать `vw` для шрифтов на первых порах |
| Media query не срабатывает | Проверить скобки, единицы (`768px`, не `768`) |
