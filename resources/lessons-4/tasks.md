# Практические задачи — Урок 4

**Время на занятии:** 38–55 мин (~17 минут)  
**Проект:** твой HTML/CSS-проект из предыдущих уроков (например, `my-first-site`)  
**Порядок:** задачи идут по нарастающей сложности — каждая следующая дополняет предыдущую

> Открой терминал в VS Code (**Terminal → New Terminal**) и убедись, что находишься в папке проекта: `cd путь/к/проекту`

---

## Задача 1 — «Инициализация репозитория» (3 мин)

### Задание

Подключи Git к своему проекту:

1. Открой терминал в папке проекта
2. Выполни `git init`
3. Проверь статус командой `git status`
4. Убедись, что появилась скрытая папка `.git` (в VS Code: View → Show Hidden Files, или проверь через `ls -la`)

### Критерии выполнения

- [ ] Команда `git init` выполнена без ошибок
- [ ] `git status` показывает `On branch main` (или `master`)
- [ ] В папке проекта есть скрытая папка `.git`

### Подсказка

```bash
cd ~/Documents/my-first-site
git init
git status
```

---

## Задача 2 — «Первый коммит» (4 мин)

### Задание

Создай первый коммит с основными файлами проекта:

1. Добавь файл `index.html` в staging: `git add index.html`
2. Если есть `style.css` — добавь его тоже
3. Создай коммит с сообщением: `"Создана главная страница"`
4. Проверь историю: `git log --oneline`

### Критерии выполнения

- [ ] Выполнен `git add` для `index.html`
- [ ] Создан коммит с осмысленным сообщением
- [ ] `git log --oneline` показывает один коммит
- [ ] `git status` показывает `nothing to commit, working tree clean` (или только неотслеживаемые файлы)

### Подсказка

```bash
git add index.html
git commit -m "Создана главная страница"
git log --oneline
```

## Задача 3 — «Второй коммит» (4 мин)

### Задание

Внеси изменение в проект и создай второй коммит:

1. Добавь или измени что-то в проекте (например, новый абзац в `index.html` или подключи `style.css`)
2. Сохрани файл (`Cmd+S` / `Ctrl+S`)
3. Проверь статус: `git status` — файл должен быть в `modified` или `untracked`
4. Добавь изменения и создай коммит с описательным сообщением

### Критерии выполнения

- [ ] В проекте есть реальное изменение (не пустой коммит)
- [ ] Сообщение коммита описывает, что изменилось
- [ ] `git log --oneline` показывает 2 коммита
- [ ] Самый свежий коммит — сверху

### Подсказка

```bash
# После редактирования файла:
git status
git add index.html
git commit -m "Добавлен раздел «Обо мне»"
git log --oneline
```

## Задача 4 — «Третий коммит и .gitignore» (4 мин)

### Задание

Создай `.gitignore` и сделай третий коммит:

1. Создай файл `.gitignore` в корне проекта
2. Добавь в него минимум 2 правила (например, `.DS_Store` и `*.log`)
3. Внеси ещё одно изменение в проект (или добавь `style.css`, если его ещё нет в истории)
4. Закоммить `.gitignore` и изменения одним или двумя коммитами

### Критерии выполнения

- [ ] Файл `.gitignore` создан в корне проекта
- [ ] В `.gitignore` есть минимум 2 правила
- [ ] `git log --oneline` показывает 3 коммита
- [ ] Все коммиты имеют понятные сообщения

### Подсказка

```gitignore
# .gitignore
.DS_Store
*.log
Thumbs.db
```

```bash
git add .gitignore style.css
git commit -m "Добавлен .gitignore и стили"
git log --oneline
```

## Задача 5 — «Публикация на GitHub» (6 мин)

### Задание

Выложи проект на GitHub:

1. Создай аккаунт на [github.com](https://github.com) (если ещё нет)
2. Создай **новый пустой** репозиторий (без README и .gitignore)
3. Подключи remote: `git remote add origin <url>`
4. Отправь код: `git push -u origin main`
5. Открой репозиторий в браузере и убедись, что файлы на месте

### Критерии выполнения

- [ ] Репозиторий создан на GitHub
- [ ] `git remote -v` показывает URL репозитория
- [ ] `git push` выполнен без ошибок
- [ ] На GitHub видны файлы проекта (`index.html` и др.)
- [ ] История коммитов отображается на GitHub (вкладка Commits)

### Подсказка

```bash
git remote add origin https://github.com/твой-username/my-first-site.git
git push -u origin main
```

> Если ветка называется `master`, а не `main`: `git push -u origin master`

> При запросе пароля используй **Personal Access Token**, а не пароль от аккаунта GitHub.
