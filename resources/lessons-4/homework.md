# Домашнее задание — Урок 4

**Задание:** «README для проекта»  
**Время:** ~30–45 минут  
**Файл:** `README.md` в корне проекта

---

## Описание

Создай файл `README.md` — описание своего проекта на GitHub. README — это «визитка» репозитория: первое, что видят люди, когда открывают твой проект. Хороший README показывает, что ты умеешь не только писать код, но и документировать свою работу.

---

## Требования

Файл `README.md` должен содержать:

1. **Заголовок проекта** — `# Название проекта` (например, `# Моя первая визитка`)
2. **Краткое описание** — 2–3 предложения: что это за проект и для чего он создан
3. **Скриншот или превью** — ссылка на изображение проекта (можно использовать placeholder или скриншот страницы)
4. **Раздел «Технологии»** — список использованных технологий (`HTML`, `CSS` и т.д.)
5. **Раздел «Как открыть»** — пошаговая инструкция: скачать/клонировать и открыть `index.html` в браузере
6. **Раздел «Структура проекта»** — дерево файлов в виде code block
7. **Раздел «Автор»** — твоё имя и ссылка на GitHub-профиль
8. **Лицензия** (опционально) — например, `MIT` или «Свободное использование в учебных целях»

После создания файла:

9. Закоммить `README.md` с сообщением `"Добавлен README"`
10. Отправить на GitHub: `git push`

---

## Пример структуры

```markdown
# Моя первая визитка

Одностраничный сайт-визитка, созданный в рамках курса по веб-разработке.
Проект демонстрирует базовые навыки HTML и CSS.

![Превью проекта](https://placehold.co/600x400?text=My+Site)

## Технологии

- HTML5
- CSS3
- Git / GitHub

## Как открыть

1. Скачай репозиторий или клонируй:
   ```bash
   git clone https://github.com/username/my-first-site.git
   ```
2. Открой файл `index.html` в браузере (двойной клик или Live Server)

## Структура проекта

```
my-first-site/
├── index.html      # Главная страница
├── style.css       # Стили
├── images/         # Изображения
├── .gitignore      # Игнорируемые файлы
└── README.md       # Описание проекта
```

## Автор

**Алексей Петров** — [GitHub](https://github.com/username)

---

Учебный проект. Свободное использование в образовательных целях.
```

## Критерии оценки

| Критерий | Балл |
| --- | --- |
| Файл `README.md` в корне проекта | обязательно |
| Есть заголовок `#` с названием проекта | обязательно |
| Есть описание проекта (минимум 2 предложения) | обязательно |
| Есть раздел «Технологии» со списком | обязательно |
| Есть раздел «Как открыть» с инструкцией | обязательно |
| Есть раздел «Структура проекта» | обязательно |
| Есть раздел «Автор» со ссылкой на GitHub | обязательно |
| README закоммичен и отправлен на GitHub (`git push`) | обязательно |
| Markdown оформлен корректно (заголовки, списки, code blocks) | обязательно |

## Бонус (по желанию)

Выполни дополнительные пункты для углубления знаний:

1. **Скриншот** — сделай реальный скриншот своего сайта, сохрани в `images/screenshot.png` и вставь в README: `![Превью](images/screenshot.png)`
2. **Badges** — добавь «бейджи» технологий (можно найти на [shields.io](https://shields.io)):
   ```markdown
   ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
   ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
   ```
3. **Ссылка на сайт** — если настроишь GitHub Pages, добавь ссылку «Посмотреть сайт» в README

## Как сдать

1. Убедись, что `README.md` отображается на главной странице репозитория на GitHub
2. Проверь, что все разделы читаются корректно (заголовки, списки, код)
3. Отправь ссылку на репозиторий преподавателю или покажи на следующем занятии

---

## Частые ошибки — проверь себя

- [ ] Файл называется `README.md`, а не `readme.md` или `README.txt`
- [ ] Заголовки в Markdown начинаются с `#` (с пробелом после)
- [ ] Code block для структуры проекта обёрнут в тройные обратные кавычки ` ``` `
- [ ] Ссылка на GitHub-профиль рабочая (открывается в браузере)
- [ ] После создания README выполнен `git add`, `git commit` и `git push`
- [ ] На GitHub в разделе Commits виден коммит с README
