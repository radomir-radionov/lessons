## Цели урока

К концу занятия ученик сможет:

1. Объяснить, зачем нужна система контроля версий (VCS) и чем Git отличается от GitHub
2. Инициализировать репозиторий и создавать коммиты (`git init`, `add`, `commit`, `status`, `log`)
3. Настроить `.gitignore` и подключить удалённый репозиторий на GitHub
4. Отправить проект на GitHub командой `git push`

**Результат:** ученик инициализирует Git в своём проекте, делает 3 коммита и публикует код на GitHub.

## Краткое содержание блоков

### Блок 1 — Введение (0–7 мин)

- Зачем нужен контроль версий: история изменений, откат, совместная работа
- Git — локальная система; GitHub — хостинг репозиториев
- Ключевые определения: VCS, репозиторий, коммит, ветка (упоминание)

### Блок 2 — Установка и `git init` (7–15 мин)

- Проверка: `git --version`
- Настройка `user.name` и `user.email` (один раз)
- `git init` в папке проекта — появляется скрытая папка `.git`
- Демо: `git status` в пустом репозитории

### Блок 3 — add, commit, status (15–25 мин)

- Три состояния файла: modified → staged → committed
- `git add .` / `git add <файл>` — подготовка к коммиту
- `git commit -m "сообщение"` — сохранение снимка
- `git status` — проверка состояния в любой момент

### Блок 4 — log и `.gitignore` (25–32 мин)

- `git log --oneline` — просмотр истории
- Зачем нужен `.gitignore`: исключить лишние файлы (`.DS_Store`, `node_modules`)
- Создать `.gitignore` в корне проекта

### Блок 5 — GitHub и push (32–38 мин)

- Создать пустой репозиторий на github.com (без README)
- `git remote add origin <url>`
- `git push -u origin main` (или `master`)
- Показать проект в браузере на GitHub

- Задачи 1–5 из [tasks.md](tasks.md) (~17 мин)
- Если ученик быстрый — все 5 задач; если медленный — минимум задачи 1–3 + push в ДЗ

### Блок 7 — Итог (55–60 мин)

## Частые проблемы (проговорить при настройке)

| Проблема                                      | Решение                                                                                  |
| --------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `git: command not found`                      | Установить Git с [git-scm.com](https://git-scm.com/) и перезапустить терминал            |
| `Please tell me who you are` при коммите      | Выполнить `git config --global user.name` и `user.email`                                 |
| `fatal: not a git repository`                 | Убедиться, что `git init` выполнен в корне проекта и терминал открыт в нужной папке      |
| `error: failed to push` / `rejected`           | Сначала `git pull`, затем `git push`; на первом push — проверить URL remote              |
| `main` vs `master` — ветка не совпадает       | Посмотреть `git branch`, использовать имя своей ветки в `push`                           |
| Закоммитил лишние файлы (`.DS_Store`)         | Добавить в `.gitignore`, удалить из индекса: `git rm --cached <файл>`                    |
| GitHub просит логин/пароль                    | Использовать Personal Access Token вместо пароля или настроить SSH-ключ (помочь вне урока) |
