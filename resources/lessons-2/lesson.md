## 1. Введение: что такое CSS

HTML задаёт **структуру** страницы. Без CSS браузер показывает чёрный текст на белом фоне.

**CSS (Cascading Style Sheets)** — язык стилей: цвета, шрифты, отступы, фон, размеры.

> HTML говорит: «это заголовок». CSS говорит: «заголовок синий, крупный, с отступом снизу».

### Аналогия

| Часть      | Роль                                 |
| ---------- | ------------------------------------ |
| HTML       | Стены, двери — структура             |
| CSS        | Обои, мебель — оформление            |
| JavaScript | Кнопки, автоматика — интерактивность |

### Синтаксис CSS

```css
селектор {
  свойство: значение;
  другое-свойство: другое-значение;
}
```

### Ключевые понятия

| Термин          | Определение                                              |
| --------------- | -------------------------------------------------------- |
| **CSS**         | Язык описания внешнего вида HTML-документов              |
| **Селектор**    | Указывает, к каким элементам применить стили             |
| **Свойство**    | Характеристика оформления: `color`, `font-size`, `margin` |
| **Значение**    | Конкретная настройка: `red`, `16px`, `bold`              |
| **CSS-правило** | Пара «свойство: значение;» внутри блока `{ }`          |

## 2. Подключение стилей к странице

| Способ              | Где                          | Когда использовать              |
| ------------------- | ---------------------------- | ------------------------------- |
| Inline              | `style=""` на элементе       | Только для быстрых экспериментов |
| `<style>` в `<head>` | CSS внутри HTML             | Маленькие одностраничные файлы  |
| Внешний `.css`      | `<link rel="stylesheet">`    | **Основной способ в проектах**  |

### Inline (не рекомендуется)

```html
<p style="color: red; font-size: 18px;">Красный текст</p>
```

### Внешний файл (рекомендуется)

```html
<head>
  <link rel="stylesheet" href="styles.css" />
</head>
```

```css
/* styles.css */
h1 { color: navy; }
p { font-size: 16px; line-height: 1.5; }
```

### Структура проекта

```
my-card/
├── index.html
├── styles.css
└── images/
    └── photo.jpg
```

`<link>` размещается в `<head>`, **до** `</head>`.

## 3. Селекторы

| Тип        | CSS-синтаксис | HTML-пример              | Примечание                    |
| ---------- | ------------- | ------------------------ | ----------------------------- |
| По тегу    | `p { }`       | `<p>…</p>`               | Все элементы с этим тегом     |
| По классу  | `.intro { }`  | `class="intro"`          | Можно повторять, предпочтительно |
| По id      | `#main { }`   | `id="main"`              | Один на страницу              |
| Группа     | `h1, h2 { }`  | —                        | Одинаковые стили для списка   |
| Потомок    | `.card p { }` | `<div class="card"><p>`  | `p` внутри `.card`            |

```css
p { color: #333; }

.intro { color: gray; font-style: italic; }

#main-title { color: navy; }

h1, h2, h3 {
  font-family: "Roboto", sans-serif;
  color: #1a1a2e;
}

.card p { margin-bottom: 12px; }
```

Несколько классов на одном элементе: `class="intro highlight"`.

> Для стилизации предпочитай **классы**, а не id.

## 4. Каскад и специфичность

**Cascading** — браузер выбирает итоговый стиль, если правил несколько.

### Приоритет (от слабого к сильному)

1. **Порядок** — при равной специфичности побеждает правило **ниже** в файле
2. **Специфичность** — более «точный» селектор побеждает
3. **`!important`** — принудительный приоритет (используй редко)

| Селектор     | Пример        | Сила          |
| ------------ | ------------- | ------------- |
| По тегу      | `p`           | низкая        |
| По классу    | `.intro`      | средняя       |
| По id        | `#main-title` | высокая       |
| Inline       | `style="…"`   | очень высокая |

```css
p { color: black; }
.intro { color: gray; }   /* победит — специфичнее */
```

```css
h1 { color: red; }
h1 { color: blue; }       /* победит — написано ниже */
```

## 5. Основные свойства CSS

### Цвет и фон

```css
h1 { color: navy; }
p { color: #333333; }
body { background-color: #f5f5f5; }
.card { background-color: white; }
```

Форматы цвета: имена (`red`), HEX (`#ff0000`), RGB (`rgb(255, 0, 0)`).

### Шрифт и текст

```css
body {
  font-family: "Roboto", Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  font-size: 32px;
  font-weight: 700;
  text-align: center;
}

a { text-decoration: none; }
```

| Свойство         | Назначение                          |
| ---------------- | ----------------------------------- |
| `font-family`    | Гарнитура (список через запятую)    |
| `font-size`      | Размер текста (`px`)                |
| `font-weight`    | Толщина: `400` / `700` или `normal` / `bold` |
| `line-height`    | Межстрочный интервал (`1.6` = 160%) |
| `text-align`     | `left`, `center`, `right`           |
| `text-decoration`| Подчёркивание (`none` убирает)      |
| `border-radius`  | Скругление углов (`50%` — круглое фото) |

## 6. Блочная модель (Box Model)

Каждый элемент — прямоугольный блок из слоёв (снаружи внутрь):

```
margin → border → padding → content
```

| Свойство | Назначение                                      |
| -------- | ----------------------------------------------- |
| `margin` | Внешний отступ — между элементами               |
| `border` | Граница: `1px solid #ddd`                       |
| `padding`| Внутренний отступ — между границей и содержимым |
| `width`  | Ширина элемента                                 |

```css
.card {
  width: 600px;
  max-width: 100%;
  margin: 0 auto;          /* центрирование при заданной width */
  margin-bottom: 24px;
  padding: 24px;
  background-color: white;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}
```

**Сокращённая запись:** `padding: 10px 20px;` — верх/низ, лево/право.

### `box-sizing: border-box`

По умолчанию `width` не включает `padding` и `border`. `border-box` включает их — элемент не «раздувается»:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Добавь в начало `styles.css` на каждом проекте.

## 7. Подключение шрифтов (Google Fonts)

1. Открыть [fonts.google.com](https://fonts.google.com)
2. Выбрать шрифт (**Roboto** или **Inter**)
3. **Get font** → **Get embed code**
4. Вставить `<link>` в `<head>` **перед** `styles.css`
5. Указать `font-family` в CSS

```html
<head>
  <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet" />
  <link rel="stylesheet" href="styles.css" />
</head>
```

```css
body {
  font-family: "Roboto", Arial, sans-serif;
}

h1, h2 { font-weight: 700; }
```

> Всегда указывай **запасной шрифт** (`Arial, sans-serif`). Подключай только нужные начертания — страница загружается быстрее.

## 8. Основы БЭМ

**БЭМ** (Блок, Элемент, Модификатор) — методология именования классов.

| Часть           | Формат              | Пример              |
| --------------- | ------------------- | ------------------- |
| **Блок**        | одно слово          | `card`              |
| **Элемент**     | `блок__элемент`     | `card__title`       |
| **Модификатор** | `блок--модификатор` | `card--featured`    |

```html
<article class="card card--featured">
  <h1 class="card__title">Иван Иванов</h1>
  <p class="card__text">Веб-разработчик</p>
  <img class="card__image" src="photo.jpg" alt="Фото" />
</article>
```

```css
.card {
  padding: 24px;
  background-color: white;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}

.card--featured { border-color: navy; }
.card__title { font-size: 28px; }
.card__text { color: #666; }
```

**Правила:** блок — одно слово; элемент привязан к блоку (`card__title`, не `title`); модификатор дополняет: `class="card card--featured"`.
