1. Подключить CSS к HTML-странице тремя способами (inline, `<style>`, внешний файл)

4. Объяснить блочную модель и использовать `box-sizing: border-box`

**Результат:** ученик стилизует визитку из урока 1 — страница выглядит аккуратно и читаемо.

## Краткое содержание блоков

### Блок 1 — Введение (0–5 мин)

- CSS отвечает за внешний вид, HTML — за структуру
- Синтаксис: селектор `{ свойство: значение; }`
- DevTools → вкладка Styles — показать применённые стили

### Блок 2 — Подключение CSS (5–12 мин)

- Inline (`style=""`) — только для демо, не для проекта
- `<style>` в `<head>` — для маленьких страниц
- Внешний `styles.css` + `<link rel="stylesheet">` — основной способ
- Ученик создаёт `styles.css` и подключает к `index.html`

### Блок 3 — Селекторы и каскад (12–20 мин)

- Селекторы: по тегу, `.class`, `#id`
- Каскад: порядок, специфичность, `!important` (упомянуть, не злоупотреблять)
- Комбинатор `,` для группировки

### Блок 4 — Свойства и Box Model (20–28 мин)

- `color`, `background-color`, `font-family`, `font-size`, `font-weight`
- Box Model: content → padding → border → margin
- `box-sizing: border-box` — задать глобально в `* { }`
- DevTools: вкладка Layout / Computed — показать схему блока

### Блок 5 — Шрифты и БЭМ (28–32 мин)

- Подключить Roboto или Inter с [fonts.google.com](https://fonts.google.com)
- БЭМ: `card__title`, `card__text--accent` — переименовать 2–3 класса на примере
- Объяснить, зачем единый стиль имён

### Блок 6 — Практика (32–55 мин) · Блок 7 — Итог (55–60 мин)

- Задачи 1–5 из [tasks.md](tasks.md); визитка из ДЗ урока 1 (`index.html` + `styles.css`)
- Медленный ученик — минимум задачи 1–3; быстрый — все 5
- Итог: резюме, вопросы, выдача ДЗ «Обо мне»

## Частые проблемы

| Проблема                              | Решение                                                                 |
| ------------------------------------- | ----------------------------------------------------------------------- |
| Стили не применяются                  | Проверить путь в `<link href="styles.css">`, имя файла, сохранение      |
| Забыли точку перед классом в CSS      | `.about-text { }`, а не `about-text { }`                                |
| Нет двоеточия после свойства          | `color: red;` — двоеточие обязательно                                   |
| Забыли `;` в конце правила            | Каждое свойство заканчивается точкой с запятой                          |
| Шрифт Google не загружается           | Проверить `<link>` в `<head>` и правильное имя в `font-family`          |
| Элемент «вылезает» за границы         | Добавить `box-sizing: border-box` и проверить `width` + `padding`       |
| Стили конфликтуют                     | DevTools → Styles: какое правило перекрывает; убрать inline `style=""`  |
