# Практические задачи — Урок 2

**Время на занятии:** 32–55 мин (~23 минуты)  
**Файлы:** `index.html` (визитка из ДЗ урока 1) + `styles.css`  
**Порядок:** задачи идут по нарастающей сложности — каждая следующая дополняет предыдущую

> Если ты не сделал домашнее задание «Моя визитка» — используй демо-файл от преподавателя или быстро собери страницу с `h1`, двумя `h2`, абзацами, списками и картинкой.

## Задача 1 — «Подключение CSS» (4 мин)

### Задание

Подготовь проект к стилизации:

1. Открой папку с визиткой (`my-card` или аналог)
2. Создай файл `styles.css` в той же папке, что и `index.html`
3. Подключи его в `<head>` через `<link rel="stylesheet" href="styles.css">`
4. Добавь в `styles.css` правило, которое меняет цвет фона страницы (`body`)

### Критерии выполнения

- [ ] Файл `styles.css` создан в папке проекта
- [ ] В `<head>` есть `<link rel="stylesheet" href="styles.css">`
- [ ] Тег `<link>` стоит **после** `<meta>`, **перед** `</head>`
- [ ] Фон страницы изменился (не белый по умолчанию)
- [ ] Стили применяются после сохранения и обновления страницы

### Подсказка

```html
<link rel="stylesheet" href="styles.css" />
```

```css
body {
  background-color: #f0f4f8;
}
```

## Задача 2 — «Типографика» (5 мин)

### Задание

Настрой шрифты и цвета текста:

1. Подключи шрифт **Roboto** (или **Inter**) с [Google Fonts](https://fonts.google.com)
2. Примени шрифт ко всей странице через `body`
3. Стилизуй `h1`: увеличь размер, сделай жирным, задай цвет
4. Стилизуй `h2`: размер меньше, чем у `h1`, другой оттенок
5. Задай цвет обычного текста в абзацах `<p>`

### Критерии выполнения

- [ ] В `<head>` подключён `<link>` с Google Fonts
- [ ] `font-family` задан для `body` с запасным шрифтом (`sans-serif`)
- [ ] `h1` отличается от `h2` по размеру и/или цвету
- [ ] Текст в `<p>` имеет читаемый цвет (не чисто чёрный — например, `#333`)
- [ ] У `body` задан `line-height` для удобного чтения

### Подсказка

```css
body {
  font-family: "Roboto", Arial, sans-serif;
  line-height: 1.6;
  color: #333;
}

h1 {
  font-size: 32px;
  font-weight: 700;
  color: #1a1a2e;
}

h2 {
  font-size: 22px;
  color: #2d3a4a;
}
```

## Задача 3 — «Карточка визитки» (6 мин)

### Задание

Оформи содержимое как карточку с помощью Box Model:

1. Оберни основное содержимое в `<div class="card">` (или добавь класс `card` на `body`, если удобнее)
2. Задай карточке: белый фон, внутренние отступы (`padding`), скруглённые углы (`border-radius`)
3. Добавь тонкую границу (`border`) или лёгкую тень через `box-shadow`
4. Ограничь ширину (`width: 600px`) и отцентрируй (`margin: 0 auto`)
5. В начало `styles.css` добавь сброс `box-sizing`:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

### Критерии выполнения

- [ ] Есть элемент с классом `card`
- [ ] Карточка имеет `padding` минимум 20px
- [ ] Карточка имеет `background-color: white` (или светлый фон)
- [ ] Есть `border` или `border-radius`
- [ ] Карточка отцентрирована и не растягивается на всю ширину экрана
- [ ] В CSS есть правило `box-sizing: border-box`

### Подсказка

```html
<body>
  <div class="card">
    <!-- содержимое визитки -->
  </div>
</body>
```

```css
.card {
  width: 600px;
  max-width: 100%;
  margin: 0 auto;
  padding: 24px;
  background-color: white;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}
```

## Задача 4 — «Секции и отступы» (4 мин)

### Задание

Раздели визитку на логические секции и настрой отступы:

1. Добавь классы секциям: `card__section` (оберни каждый блок с `h2` и содержимым)
2. Задай отступ снизу между секциями (`margin-bottom`)
3. Стилизуй `<hr>`: сделай линию тоньше и светлее
4. Сделай фото круглым (`border-radius: 50%`) и задай фиксированную ширину
5. Убери подчёркивание у ссылок (`text-decoration: none`), задай им цвет

### Критерии выполнения

- [ ] Секции обёрнуты в элементы с классом `card__section`
- [ ] Между секциями есть визуальное разделение (отступ или `<hr>`)
- [ ] Изображение круглое или со скруглёнными углами
- [ ] Ссылки без подчёркивания, с заданным цветом
- [ ] Использован селектор потомка (например, `.card a`)

### Подсказка

```css
.card__section {
  margin-bottom: 24px;
}

.card img {
  width: 150px;
  border-radius: 50%;
  display: block;
  margin-bottom: 16px;
}

.card a {
  color: #2563eb;
  text-decoration: none;
}

hr {
  border: none;
  border-top: 1px solid #e0e0e0;
  margin: 24px 0;
}
```

## Задача 5 — «БЭМ-именование» (4 мин)

### Задание

Переименуй классы по методологии БЭМ и добавь модификатор:

1. Переименуй основные элементы:
   - `card__title` — для `h1`
   - `card__subtitle` — для `h2`
   - `card__text` — для абзаца «Обо мне»
   - `card__photo` — для `<img>`
   - `card__list` — для списков (или отдельно `card__skills`, `card__contacts`)
2. Добавь модификатор `card__text--accent` на `<em>` или выделенный фрагмент текста
3. Напиши CSS для каждого БЭМ-класса
4. Убедись, что страница выглядит так же или лучше, чем после задачи 4

### Критерии выполнения

- [ ] Минимум 4 класса названы по БЭМ (`блок__элемент`)
- [ ] Есть минимум 1 модификатор (`блок__элемент--модификатор`)
- [ ] В CSS нет «случайных» имён (`text1`, `blue`, `big`)
- [ ] Все стили из задач 1–4 сохранены и работают
- [ ] Страница аккуратно оформлена и читаема

### Подсказка

```html
<h1 class="card__title" id="main-title">Иван Иванов</h1>
<img class="card__photo" src="..." alt="..." />

<h2 class="card__subtitle">Обо мне</h2>
<p class="card__text">
  Мне <strong>16 лет</strong>, увлекаюсь <em class="card__text--accent">программированием</em>.
</p>
```

```css
.card__title {
  text-align: center;
}

.card__text--accent {
  color: #2563eb;
  font-style: italic;
}
```
