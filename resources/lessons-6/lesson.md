## 1. Псевдоклассы :hover и :focus

До сих пор мы стилизовали элементы в их **обычном состоянии**. Но пользователь взаимодействует со страницей: наводит курсор, кликает, переходит по Tab. Для таких **состояний** в CSS есть **псевдоклассы**.

**Псевдокласс** — ключевое слово, добавляемое к селектору через двоеточие. Оно описывает **состояние** элемента, а не отдельный HTML-тег.

```css
селектор:псевдокласс {
  свойство: значение;
}
```

### :hover — при наведении

`:hover` срабатывает, когда курсор мыши находится **над элементом**:

```css
.btn {
  background-color: #4a90d9;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  transition: background-color 0.2s;
}

.btn:hover {
  background-color: #3a7bc8;
}
```

Типичные эффекты при `:hover`:

- Изменение цвета фона или текста
- Появление тени (`box-shadow`)
- Подчёркивание ссылки
- Лёгкое увеличение (`transform: scale` — урок 7)

### :focus — при фокусе

`:focus` срабатывает, когда элемент **получает фокус** — например, при клике или нажатии Tab:

```css
.btn:focus {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}
```

> **Важно для доступности:** не убирай `outline` полностью (`outline: none`) без замены. Пользователи клавиатуры должны видеть, какой элемент активен.

### :active — при нажатии

`:active` срабатывает **в момент нажатия** кнопки мыши (пока кнопка зажата):

```css
.btn:active {
  transform: scale(0.98);
}
```

На уроке достаточно знать `:hover` и `:focus`.

---

### Определения и понятия

#### Псевдокласс

**Псевдокласс** — CSS-селектор, описывающий особое состояние элемента. Пишется через одно двоеточие: `:hover`, `:focus`, `:nth-child(2)`.

#### :hover

**`:hover`** — псевдокласс, активный когда курсор мыши находится над элементом.

#### :focus

**`:focus`** — псевдокласс, активный когда элемент получил фокус (клик, Tab, Enter).

#### :active

**`:active`** — псевдокласс, активный в момент нажатия на элемент (между mousedown и mouseup).

#### Доступность (accessibility)

**Доступность** — практика создания интерфейсов, удобных для всех пользователей, включая людей с ограничениями. Видимый `:focus` — базовое требование.

## 2. Выбор по позиции: :nth-child

Псевдокласс `:nth-child()` позволяет выбрать элемент по его **позиции** среди соседей:

```css
li:nth-child(2) {
  font-weight: bold;
}
```

Выберет **второй** дочерний элемент родителя (если это `<li>`).

### Синтаксис

| Запись | Значение |
| --- | --- |
| `:nth-child(3)` | Третий дочерний элемент |
| `:nth-child(odd)` | Нечётные (1, 3, 5, …) |
| `:nth-child(even)` | Чётные (2, 4, 6, …) |
| `:nth-child(3n)` | Каждый третий (3, 6, 9, …) |
| `:nth-child(3n+1)` | 1, 4, 7, 10, … |

### Пример: зебра-список

```css
.list li:nth-child(even) {
  background-color: #f5f5f5;
}

.list li:nth-child(odd) {
  background-color: white;
}
```

### Важно

`:nth-child` считает **все** дочерние элементы родителя, не только однотипные. Если внутри `<ul>` есть комментарий или другой тег между `<li>`, нумерация сбивается.

---

### Определения и понятия

#### :nth-child()

**`:nth-child()`** — псевдокласс для выбора элемента по номеру среди соседних дочерних элементов.

#### :first-child

**`:first-child`** — первый дочерний элемент родителя. Сокращение для `:nth-child(1)`.

#### :last-child

**`:last-child`** — последний дочерний элемент родителя.

#### Зебра-стилизация

**Зебра-стилизация** — чередование стилей строк (например, чётные — серые, нечётные — белые) для улучшения читаемости.

## 3. Псевдоэлементы ::before и ::after

**Псевдоэлементы** — виртуальные элементы, которые CSS создаёт **до** или **после** содержимого реального элемента. Они не существуют в HTML.

```css
элемент::псевдоэлемент {
  content: "...";
}
```

Пишутся через **два** двоеточия: `::before`, `::after`.

### ::before — перед содержимым

```css
.title::before {
  content: "★ ";
  color: gold;
}
```

Перед текстом заголовка появится звёздочка.

### ::after — после содержимого

```css
.link::after {
  content: " →";
  color: #4a90d9;
}
```

### Обязательное свойство content

Без `content` псевдоэлемент **не отобразится**, даже если заданы размеры:

```css
.divider::after {
  content: "";
  display: block;
  width: 100%;
  height: 2px;
  background-color: #ddd;
  margin-top: 16px;
}
```

Пустой `content: ""` — для декоративных блоков (линии, бейджи, иконки).

### Бейдж через ::after

```css
.nav__link--new::after {
  content: "NEW";
  display: inline-block;
  margin-left: 8px;
  padding: 2px 6px;
  font-size: 10px;
  background-color: #e74c3c;
  color: white;
  border-radius: 4px;
}
```

---

### Определения и понятия

#### Псевдоэлемент

**Псевдоэлемент** — виртуальная часть элемента, создаваемая CSS. Пишется через `::` (два двоеточия).

#### ::before

**`::before`** — псевдоэлемент, вставляемый как первый дочерний элемент (перед содержимым).

#### ::after

**`::after`** — псевдоэлемент, вставляемый как последний дочерний элемент (после содержимого).

#### content

**`content`** — обязательное свойство для `::before` и `::after`. Определяет текст или пустой декоративный блок.

## 4. Позиционирование: relative и absolute

Свойство `position` определяет, **как элемент располагается** на странице.

### position: static (по умолчанию)

Элемент в **обычном потоке** документа. Свойства `top`, `right`, `bottom`, `left` и `z-index` **не работают**.

### position: relative

Элемент остаётся в потоке, но может быть **сдвинут** относительно своего исходного места:

```css
.box {
  position: relative;
  top: 10px;
  left: 20px;
}
```

Главное применение `relative` — **создать контекст позиционирования** для дочерних `absolute` элементов.

### position: absolute

Элемент **вырван из потока** документа и позиционируется относительно ближайшего предка с `position` ≠ `static`:

```css
.card {
  position: relative;
}

.card__badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

Бейдж «прилипает» к правому верхнему углу карточки.

### Свойства смещения

| Свойство | Эффект |
| --- | --- |
| `top` | Смещение от верхнего края |
| `right` | Смещение от правого края |
| `bottom` | Смещение от нижнего края |
| `left` | Смещение от левого края |

Значения: пиксели (`10px`), проценты (`50%`), `auto`.

### Схема: relative + absolute

```
┌─ .card (position: relative) ─────────┐
│  ┌─ .badge (absolute, top/right) ─┐ │
│  │  -30%                           │ │
│  └─────────────────────────────────┘ │
│  [изображение]                       │
│  [заголовок]                         │
└──────────────────────────────────────┘
```

---

### Определения и понятия

#### position

**`position`** — способ позиционирования элемента: `static`, `relative`, `absolute`, `fixed`, `sticky`.

#### static

**`static`** — позиционирование по умолчанию. Элемент в обычном потоке документа.

#### relative

**`position: relative`** — элемент в потоке, но с возможностью сдвига. Создаёт контекст для `absolute` потомков.

#### absolute

**`position: absolute`** — элемент вне потока, позиционируется относительно ближайшего positioned-предка.

#### Контекст позиционирования

**Контекст позиционирования** — элемент с `position: relative/absolute/fixed/sticky`, относительно которого позиционируются `absolute` потомки.

#### Поток документа (document flow)

**Поток документа** — порядок, в котором элементы располагаются на странице по умолчанию (сверху вниз, слева направо).

## 5. Наложение слоёв: z-index

Когда элементы **накладываются** друг на друга, `z-index` определяет, кто **сверху**:

```css
.modal-overlay {
  position: fixed;
  z-index: 100;
}

.modal {
  position: absolute;
  z-index: 101;
}
```

### Правила z-index

1. Работает только у элементов с `position` ≠ `static`
2. Большее значение — **выше** (ближе к пользователю)
3. Отрицательные значения — элемент уходит «под» соседей
4. Без `z-index` порядок определяется порядком в HTML (позже в коде — выше)

### Модальное окно

Типичная структура:

```html
<div class="modal-overlay">
  <div class="modal">
    <h2>Заголовок</h2>
    <p>Текст модального окна</p>
    <button>Закрыть</button>
  </div>
</div>
```

```css
.modal-overlay {
  position: fixed;
  inset: 0;
  background-color: rgba(0, 0, 0, 0.5);
  display: flex;
  justify-content: center;
  align-items: center;
  z-index: 100;
}

.modal {
  background: white;
  padding: 32px;
  border-radius: 12px;
  z-index: 101;
}
```

`inset: 0` — сокращение для `top: 0; right: 0; bottom: 0; left: 0` (на весь экран).

---

### Определения и понятия

#### z-index

**`z-index`** — порядок наложения элементов по оси Z (глубина). Большее значение — элемент выше.

#### Overlay (оверлей)

**Overlay** — полупрозрачный слой поверх страницы, затемняющий фон. Используется под модальными окнами.

#### Модальное окно (modal)

**Модальное окно** — всплывающий блок поверх страницы, требующий внимания пользователя. Обычно с overlay-фоном.

#### rgba()

**`rgba(red, green, blue, alpha)`** — цвет с прозрачностью. `alpha` от 0 (прозрачный) до 1 (непрозрачный).
