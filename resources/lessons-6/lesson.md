## 1. Псевдоклассы :hover и :focus

**Псевдокласс** — ключевое слово через одно двоеточие. Описывает **состояние** элемента, а не отдельный HTML-тег.

```css
селектор:псевдокласс {
  свойство: значение;
}
```

| Псевдокласс | Когда активен                          |
| ----------- | -------------------------------------- |
| `:hover`    | Курсор над элементом                   |
| `:focus`    | Элемент получил фокус (клик, Tab)      |
| `:active`   | Момент нажатия (между mousedown и mouseup) |

### Интерактивная кнопка

```css
.btn {
  background-color: #4a90d9;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
}

.btn:hover {
  background-color: #3a7bc8;
}

.btn:focus {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}

.btn:active {
  transform: scale(0.98);
}
```

> **Доступность:** не убирай `outline` полностью без замены — пользователи клавиатуры должны видеть активный элемент.

Типичные эффекты `:hover`: смена цвета, `box-shadow`, подчёркивание ссылки.

## 2. Выбор по позиции: :nth-child

Псевдокласс `:nth-child()` выбирает элемент по **позиции** среди всех дочерних элементов родителя.

| Запись              | Значение                    |
| ------------------- | --------------------------- |
| `:nth-child(3)`     | Третий дочерний элемент     |
| `:nth-child(odd)`   | Нечётные (1, 3, 5, …)       |
| `:nth-child(even)`  | Чётные (2, 4, 6, …)         |
| `:nth-child(3n)`    | Каждый третий (3, 6, 9, …)  |
| `:nth-child(3n+1)`  | 1, 4, 7, 10, …              |

### Зебра-список

```css
.list li:nth-child(even) {
  background-color: #f5f5f5;
}

.list li:nth-child(odd) {
  background-color: white;
}
```

> Считаются **все** дочерние элементы, не только `<li>`. Комментарии и другие теги между `<li>` сбивают нумерацию.

## 3. Псевдоэлементы ::before и ::after

**Псевдоэлементы** — виртуальные элементы, создаваемые CSS **до** или **после** содержимого. Пишутся через **два** двоеточия.

```css
элемент::псевдоэлемент {
  content: "...";
}
```

| Псевдоэлемент | Позиция              |
| ------------- | -------------------- |
| `::before`    | Перед содержимым     |
| `::after`     | После содержимого    |

Без `content` псевдоэлемент **не отобразится**.

### Примеры

```css
.title::before {
  content: "★ ";
  color: gold;
}

.link::after {
  content: " →";
  color: #4a90d9;
}

.divider::after {
  content: "";
  display: block;
  width: 100%;
  height: 2px;
  background-color: #ddd;
  margin-top: 16px;
}
```

### Бейдж «NEW»

```css
.nav__link--new::after {
  content: "NEW";
  display: inline-block;
  margin-left: 8px;
  padding: 2px 6px;
  font-size: 10px;
  background-color: #e74c3c;
  color: white;
  border-radius: 4px;
}
```

Пустой `content: ""` — для декоративных блоков (линии, бейджи, иконки).

## 4. Позиционирование: relative и absolute

Свойство `position` определяет, как элемент располагается на странице.

| Значение   | Поведение                                                    |
| ---------- | ------------------------------------------------------------ |
| `static`   | По умолчанию — в потоке документа. `top`/`left`/`z-index` не работают |
| `relative` | В потоке, но можно сдвинуть. Создаёт **контекст** для `absolute` потомков |
| `absolute` | Вне потока — позиционируется относительно ближайшего предка с `position` ≠ `static` |

### relative — сдвиг и контекст

```css
.box {
  position: relative;
  top: 10px;
  left: 20px;
}
```

Главное применение — **якорь** для дочерних `absolute` элементов.

### absolute — бейдж на карточке

```css
.card {
  position: relative;
}

.card__badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

### Свойства смещения

| Свойство | Эффект                    |
| -------- | ------------------------- |
| `top`    | От верхнего края          |
| `right`  | От правого края           |
| `bottom` | От нижнего края           |
| `left`   | От левого края            |

Значения: пиксели (`10px`), проценты (`50%`), `auto`.

```
┌─ .card (position: relative) ─────────┐
│  ┌─ .badge (absolute, top/right) ─┐  │
│  │  -30%                           │  │
│  └─────────────────────────────────┘  │
│  [изображение]                         │
│  [заголовок]                           │
└────────────────────────────────────────┘
```

## 5. Наложение слоёв: z-index

Когда элементы **накладываются**, `z-index` определяет, кто **сверху**.

### Правила

1. Работает только у элементов с `position` ≠ `static`
2. Большее значение — **выше** (ближе к пользователю)
3. Без `z-index` порядок определяется порядком в HTML

### Модальное окно

```html
<div class="modal-overlay">
  <div class="modal">
    <h2>Заголовок</h2>
    <p>Текст модального окна</p>
    <button>Закрыть</button>
  </div>
</div>
```

```css
.modal-overlay {
  position: fixed;
  inset: 0;
  background-color: rgba(0, 0, 0, 0.5);
  display: flex;
  justify-content: center;
  align-items: center;
  z-index: 100;
}

.modal {
  background: white;
  padding: 32px;
  border-radius: 12px;
  z-index: 101;
}
```

`inset: 0` — сокращение для `top/right/bottom/left: 0` (на весь экран).  
`rgba(0, 0, 0, 0.5)` — чёрный с 50% прозрачностью.

## Словарь терминов

| Термин                    | Краткое определение                              |
| ------------------------- | ------------------------------------------------ |
| Псевдокласс               | Состояние элемента (`:hover`, `:focus`)          |
| Псевдоэлемент             | Виртуальная часть элемента (`::before`, `::after`) |
| :hover                    | Стиль при наведении курсора                      |
| :focus                    | Стиль при фокусе элемента                        |
| :active                   | Стиль при нажатии                                |
| :nth-child()              | Выбор по номеру среди соседей                    |
| ::before / ::after        | Псевдоэлементы до/после содержимого             |
| content                   | Текст или пустой блок для псевдоэлемента         |
| position                  | Способ позиционирования элемента                 |
| static                    | Позиционирование по умолчанию                    |
| relative                  | Сдвиг относительно себя, контекст для absolute   |
| absolute                  | Позиционирование вне потока                      |
| z-index                   | Порядок наложения слоёв                          |
| Контекст позиционирования | Positioned-предок для absolute                   |
| Поток документа           | Порядок элементов на странице по умолчанию       |
| Overlay                   | Полупрозрачный слой поверх страницы              |
| Модальное окно            | Всплывающий блок поверх контента                 |
| rgba()                    | Цвет с прозрачностью                             |
| Доступность               | Удобство интерфейса для всех пользователей         |
