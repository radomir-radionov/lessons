## Цели урока

К концу занятия ученик сможет:

1. Стилизовать интерактивные состояния элементов с помощью псевдоклассов `:hover` и `:focus`
2. Выбирать элементы по позиции через `:nth-child` и создавать декоративные элементы через `::before` / `::after`
3. Позиционировать элементы с `position: relative` и `position: absolute`
4. Управлять наложением слоёв через `z-index`

**Результат:** ученик создаёт интерактивную кнопку, стилизованный список, бейдж через `::after` и модальное окно с абсолютным позиционированием.

## Краткое содержание блоков

### Блок 1 — Псевдоклассы (0–10 мин)

- Псевдокласс — состояние элемента, а не отдельный тег
- `:hover` — при наведении курсора
- `:focus` — при фокусе (клавиатура, Tab)
- `:active` — при нажатии (кратко)
- Доступность: не убирай `outline` без замены

### Блок 2 — nth-child (10–16 мин)

- `:nth-child(n)` — n-й дочерний элемент
- `:nth-child(even)` / `:nth-child(odd)` — чётные/нечётные
- `:nth-child(3n)` — каждый третий
- Паттерн: зебра-таблица, выделение каждой второй строки списка

### Блок 3 — Псевдоэлементы (16–22 мин)

- `::before` и `::after` — виртуальные элементы
- Обязательное свойство `content: ""`
- `display: inline-block` или `block` для размеров
- Бейдж, декоративная линия, иконка-точка

### Блок 4 — Позиционирование (22–32 мин)

- `position: static` — по умолчанию, в потоке документа
- `position: relative` — сдвиг относительно себя; создаёт контекст для `absolute`
- `position: absolute` — вырывается из потока, позиционируется относительно ближайшего `relative` предка
- `top`, `right`, `bottom`, `left` — смещение

### Блок 5 — z-index (32–38 мин)

- `z-index` — порядок наложения (только у `position` ≠ `static`)
- Модальное окно: overlay + карточка по центру
- Типичные значения: overlay `z-index: 100`, modal `z-index: 101`

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| `::before` не виден | Добавить `content: ""` и задать `display`, `width`, `height` |
| `absolute` элемент «улетает» | У предка задать `position: relative` |
| `z-index` не работает | Проверить, что у элемента `position` не `static` |
| Hover не срабатывает на мобильном | Нормально для touch; `:focus` важнее для доступности |
| `nth-child` выбирает не то | Считаются **все** дочерние элементы, не только `<li>` |
| Модалка не по центру | Использовать flex на overlay или `top: 50%; left: 50%; transform: translate(-50%, -50%)` (transform — урок 7) |

## Что НЕ входит в урок 6

- `position: fixed` и `sticky` — уроки 9–10
- `:not()`, `:first-child`, `:last-child` подробно — углубление
- `transition` и `animation` — урок 13
- JavaScript для открытия/закрытия модалки — позже
- `transform` подробно — урок 7
