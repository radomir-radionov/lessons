## Цели урока

К концу занятия ученик сможет:

1. Объяснить разницу между desktop-first и mobile-first
2. Писать стили mobile-first с `min-width` media queries
3. Использовать стандартные брейкпоинты 768px и 1024px
4. Правильно настроить `<meta name="viewport">` и понимать его параметры

**Результат:** ученик переписывает макет с desktop-first на mobile-first и проверяет на трёх ширинах экрана.

## Краткое содержание блоков

### Блок 1 — Mobile-first (0–10 мин)

- Desktop-first (урок 9) vs mobile-first
- Базовые стили для мобильного, расширение через `min-width`
- Преимущества: меньше кода, быстрее на мобильных

### Блок 2 — Брейкпоинты (10–18 мин)

- 768px — планшет (portrait) / крупный телефон
- 1024px — планшет (landscape) / маленький ноутбук
- Таблица: мобильный < 768, планшет 768–1023, десктоп ≥ 1024

### Блок 3 — Meta viewport (18–25 мин)

- `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- `width=device-width`, `initial-scale`, `maximum-scale`
- Что происходит без meta viewport на телефоне

### Блок 4 — Паттерны (25–32 мин)

- Переписать `@media (max-width)` → `@media (min-width)`
- Типографика: базовый размер на мобильном, увеличение на десктопе
- Скрытие/показ элементов: `display: none` → `display: block`

### Блок 5 — Практика (32–55 мин)

- Задачи 1–5 из [tasks.md](tasks.md)
- Минимум: задачи 1–4; задача 5 — по темпу или в ДЗ

### Блок 6 — Итог (55–60 мин)

- Резюме, 4 вопроса
- Выдача ДЗ «Одна секция — два экрана»

## Частые проблемы

| Проблема | Решение |
| -------- | ------- |
| Стили desktop-first остались | Переписать: база = мобильный, `min-width` для расширения |
| На телефоне мелкий текст без zoom | Проверить `<meta name="viewport">` |
| Брейкпоинт не срабатывает | `min-width: 768px` срабатывает при ≥ 768, не при < 768 |
| Дублирование стилей | Вынести общее в базу, в media query — только отличия |
| Конфликт `max-width` и `min-width` | Выбрать один подход (mobile-first) и не смешивать |
