## 1. Подход mobile-first

### Что мы делали на уроке 9

На [уроке 9](../lessons-9/lesson.md) мы использовали подход **desktop-first**:

1. Базовые стили — для широкого экрана (3 колонки в ряд)
2. Media query с `max-width` — для узкого экрана (колонки в столбик)

```css
/* Desktop-first */
.columns {
  display: flex;
}

@media (max-width: 768px) {
  .columns {
    flex-direction: column;
  }
}
```

### Подход mobile-first

**Mobile-first** — обратная логика:

1. **Базовые стили** — для мобильного (одна колонка, простая раскладка)
2. **Media query с `min-width`** — постепенно **добавляем** сложность для широких экранов

```css
/* Mobile-first */
.columns {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

@media (min-width: 768px) {
  .columns {
    flex-direction: row;
  }

  .column {
    flex: 1;
  }
}
```

### Зачем mobile-first

| Преимущество | Объяснение |
| ------------ | ---------- |
| Меньше кода на мобильных | Браузер не загружает лишние стили для узкого экрана |
| Приоритет контенту | Сначала думаем о главном — что видит пользователь на телефоне |
| Проще расширять | Добавляем сложность, а не убираем |
| Статистика | Большинство пользователей заходят с мобильных |

### Аналогия

**Desktop-first** — строишь большой дом, потом сносишь комнаты для квартиры.  
**Mobile-first** — начинаешь с однокомнатной квартиры, потом достраиваешь этажи.

---

### Определения и понятия

#### Mobile-first

**Mobile-first** — методология вёрстки, при которой базовые CSS-стили пишутся для мобильных устройств, а media queries с `min-width` расширяют макет для планшетов и десктопов.

#### Desktop-first

**Desktop-first** — методология, при которой базовые стили пишутся для широкого экрана, а media queries с `max-width` адаптируют макет для узких экранов. Использовали на [уроке 9](../lessons-9/lesson.md).

#### Progressive enhancement (прогрессивное улучшение)

**Прогрессивное улучшение** — принцип: базовая версия работает везде, а на мощных устройствах и широких экранах добавляются улучшения. Mobile-first — частный случай этого принципа.

## 2. Брейкпоинты

### Что такое брейкпоинт

**Брейкпоинт (breakpoint)** — конкретная ширина экрана, при которой меняется раскладка или стили. В mobile-first брейкпоинты задаются через `min-width`.

### Стандартные брейкпоинты

В этом курсе используем три зоны:

| Зона | Ширина | Устройства | Media query |
| ---- | ------ | ---------- | ----------- |
| Мобильный | < 768px | Телефоны | Базовые стили (без query) |
| Планшет | 768px – 1023px | Планшеты, крупные телефоны | `@media (min-width: 768px)` |
| Десктоп | ≥ 1024px | Ноутбуки, мониторы | `@media (min-width: 1024px)` |

### Пример: три уровня раскладки

```css
/* 1. Мобильный — база */
.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* 2. Планшет */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 3. Десктоп */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
  }
}
```

### Каскад media queries

Media queries с `min-width` **накапливаются**: стили из `768px` действуют и на `1024px`, пока их не переопределят. Поэтому в каждом следующем брейкпоинте пиши **только отличия**.

```css
h1 {
  font-size: 28px; /* мобильный */
}

@media (min-width: 768px) {
  h1 {
    font-size: 36px; /* планшет + десктоп */
  }
}

@media (min-width: 1024px) {
  h1 {
    font-size: 48px; /* только десктоп */
  }
}
```

> **Важно:** брейкпоинты — это ориентиры, не закон природы. Подбирай под свой макет. 768px и 1024px — распространённые значения в индустрии.

---

### Определения и понятия

#### Брейкпоинт (breakpoint)

**Брейкпоинт** — точка ширины viewport, при пересечении которой применяются новые стили. В mobile-first задаётся через `min-width`.

#### `@media (min-width: ...)`

**`min-width`** в media query — условие «если ширина viewport **не меньше** указанного значения». Стили применяются на экранах широких и равных заданной ширине.

#### 768px

**768px** — распространённый брейкпоинт между мобильным и планшетом. Соответствует ширине iPad в portrait и многих Android-планшетов.

#### 1024px

**1024px** — распространённый брейкпоинт между планшетом и десктопом. Соответствует iPad в landscape и маленьким ноутбукам.

## 3. Meta viewport подробно

### Зачем нужен viewport

На [уроке 1](../lessons-1/lesson.md) мы добавили meta viewport одной строкой. Сегодня разберём **подробно**, что она делает.

Без `<meta name="viewport">` мобильный браузер считает, что страница рассчитана на экран ~980px, и **уменьшает** её, чтобы влезла на телефон. Текст становится мелким, элементы — крошечными.

### Стандартная запись

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

### Разбор атрибутов `content`

| Параметр | Значение | Что делает |
| -------- | -------- | ---------- |
| `width=device-width` | — | Ширина viewport = ширина экрана устройства (375px на iPhone, 390px и т.д.) |
| `initial-scale=1.0` | 1.0 | Начальный масштаб 100%, без уменьшения |
| `maximum-scale=1.0` | 1.0 | (опционально) Запрет увеличения — **не рекомендуется**, мешает доступности |
| `user-scalable=no` | — | (опционально) Запрет зума — **не рекомендуется** |

### Рекомендуемая запись

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Этого достаточно для 99% проектов. Не блокируй зум — пользователи с плохим зрением должны иметь возможность увеличить текст.

### Демонстрация проблемы

1. Создай HTML-страницу **без** meta viewport
2. Открой на телефоне или в DevTools (iPhone)
3. Страница выглядит «уменьшенной» — как миниатюра десктопа
4. Добавь meta viewport → страница отображается в натуральную величину

### Связь viewport и CSS

- **CSS-пиксели** на мобильном: 1px в CSS ≈ несколько физических пикселей (device pixel ratio)
- **Ширина viewport** в DevTools (375px) — это CSS-пиксели, с которыми работают media queries
- Media query `@media (min-width: 768px)` срабатывает, когда **CSS-ширина** viewport ≥ 768px

---

### Определения и понятия

#### Meta viewport

**Meta viewport** — HTML-тег `<meta name="viewport">`, который сообщает мобильному браузеру, как масштабировать страницу. Без него мобильный браузер эмулирует широкий экран.

#### `width=device-width`

**`width=device-width`** — параметр viewport, устанавливающий ширину области просмотра равной физической ширине экрана устройства в CSS-пикселях.

#### `initial-scale`

**`initial-scale`** — начальный уровень масштабирования страницы. `1.0` = 100%, без уменьшения и увеличения при загрузке.

#### CSS-пиксель

**CSS-пиксель** — логическая единица измерения в веб-разработке. На Retina-экранах один CSS-пиксель может соответствовать 2–3 физическим пикселям.

#### Device pixel ratio

**Device pixel ratio (DPR)** — соотношение физических пикселей экрана к CSS-пикселям. На iPhone DPR часто равен 2 или 3.

## 4. Практические паттерны mobile-first

### Паттерн 1: колонки

```css
/* Мобильный: столбик */
.cards {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

/* Планшет+: ряд */
@media (min-width: 768px) {
  .cards {
    flex-direction: row;
  }

  .card {
    flex: 1;
  }
}
```

### Паттерн 2: шапка

```css
/* Мобильный: вертикально */
.header__inner {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 12px;
  padding: 16px;
}

/* Планшет+: горизонтально */
@media (min-width: 768px) {
  .header__inner {
    flex-direction: row;
    justify-content: space-between;
  }
}
```

### Паттерн 3: скрытие элементов

```css
/* Мобильный: скрыть боковую панель */
.sidebar {
  display: none;
}

/* Десктоп: показать */
@media (min-width: 1024px) {
  .sidebar {
    display: block;
  }
}
```

### Паттерн 4: контейнер с padding

```css
.container {
  padding: 0 16px; /* мобильный */
}

@media (min-width: 768px) {
  .container {
    padding: 0 24px;
  }
}

@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 32px;
  }
}
```

### Переписывание desktop-first → mobile-first

| Desktop-first | Mobile-first |
| ------------- | ------------ |
| База = широкий экран | База = узкий экран |
| `@media (max-width: 768px)` | `@media (min-width: 768px)` |
| Убираем сложность | Добавляем сложность |
| `flex-direction: column` в query | `flex-direction: row` в query |

**Алгоритм переписывания:**

1. Возьми стили из `max-width` query — это твоя **база**
2. Возьми стили вне query — перенеси в `min-width` query
3. Удали старый `max-width` query

---

### Определения и понятия

#### `min-width` (в media query)

**`min-width`** — условие media query: стили применяются, когда ширина viewport **больше или равна** указанному значению. Основа mobile-first.

#### Каскад media queries

**Каскад media queries** — стили из меньших брейкпоинтов наследуются большими, пока не переопределены. Порядок: база → 768px → 1024px.

#### Скрытие на мобильном

**Скрытие на мобильном** — паттерн `display: none` в базовых стилях и `display: block` (или `flex`) в media query для десктопа.
