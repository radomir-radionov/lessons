# План занятия — Урок 16: Финальный проект (часть 2)

**Модуль:** HTML, CSS, Git  
**Длительность:** 60 минут  
**Формат:** проектное занятие  
**Материалы:** [lesson.md](lesson.md) · [tasks.md](tasks.md) · [homework.md](homework.md)

---

## Цели урока

К концу занятия ученик сможет:

1. Доработать лендинг с Flexbox и CSS Grid
2. Сделать адаптивную вёрстку (mobile-first или desktop-first)
3. Добавить рабочую форму обратной связи и анимации
4. Отполировать проект и подготовить к финальной сдаче

**Результат:** ученик сдаёт готовый лендинг, соответствующий критериям из урока 15 + требованиям этапа 2.

## Краткое содержание блоков

### Блок 1 — Требования (0–8 мин)

- Что должно быть готово к концу урока
- Связь с критериями из урока 15

### Блок 2 — Flex и Grid (8–20 мин)

- Hero: flex для выравнивания
- Сетка преимуществ: grid 3 колонки → 1 на мобильном
- Навигация: flex + gap

### Блок 3 — Адаптив (20–30 мин)

- `@media (max-width: 768px)` — типовой брейкпоинт
- Скрытие/показ элементов, стек колонок

### Блок 4 — Практика (30–52 мин)

- Задачи из [tasks.md](tasks.md)
- Индивидуальная помощь по блокерам

### Блок 5 — Финальная проверка (52–58 мин)

- Пройти [homework.md](homework.md) как чеклист сдачи
- Последний коммит и push на GitHub

### Блок 6 — Итог (58–60 мин)

- Дедлайн, формат сдачи (ссылка на репозиторий)

---

## Что НЕ входит в урок 16

- Бэкенд и отправка формы на сервер — форма только вёрстка + валидация HTML5
- JavaScript для интерактива — опциональный бонус
- Полноценный деплой с CI/CD — только GitHub Pages по желанию
