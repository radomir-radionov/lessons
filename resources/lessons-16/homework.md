# Сдача проекта — Урок 16

**Формат:** финальная сдача (не обычное домашнее задание)  
**Проект:** одностраничный лендинг из [урока 15](../lessons-15/lesson.md)  
**Дедлайн:** согласуй с преподавателем (обычно — конец урока 16 или +3 дня)

---

## Как сдать проект

1. **Ссылка на GitHub** — репозиторий с актуальным кодом (публичный или с доступом преподавателю)
2. **Демонстрация** — открой `index.html` в браузере на занятии или пришли скриншоты (десктоп + мобильный)
3. **README** — в репозитории должно быть описание проекта

### Формат отправки

```
Тема: Сдача финального проекта — [Твоё имя]

Ссылка на GitHub: https://github.com/username/final-project
Тема лендинга: [название]

Комментарий (опционально): что было сложнее всего, что понравилось
```

## Чеклист финальной сдачи

Отметь каждый пункт перед сдачей.

### HTML и структура

- [ ] Валидная HTML5-структура (`DOCTYPE`, `html`, `head`, `body`)
- [ ] `<meta charset="UTF-8">` и `<meta name="viewport">`
- [ ] Семантические теги: `header`, `main`, `section`, `footer`
- [ ] Все 7 секций присутствуют: hero, about, features, gallery, contact, header, footer
- [ ] Якорная навигация работает
- [ ] У всех `<img>` есть осмысленный `alt`
- [ ] Форма: `label`, `input`, `textarea`, `button type="submit"`

### CSS и layout

- [ ] Подключены `reset.css` и `style.css` (или эквивалент)
- [ ] CSS-переменные в `:root` (минимум 3)
- [ ] **Flexbox** использован минимум в 2 местах (header, hero)
- [ ] **CSS Grid** использован минимум в 1 месте (features или gallery)
- [ ] Контент ограничен по ширине (`max-width` + `margin: 0 auto`)
- [ ] Единый стиль: цвета, скругления, отступы согласованы

### Адаптивность

- [ ] `@media (max-width: 768px)` (или mobile-first `min-width`)
- [ ] На ширине **375px** нет горизонтального скролла
- [ ] Hero и карточки корректно стекаются на мобильном
- [ ] Текст читаем на маленьком экране

### Форма

- [ ] Поля стилизованы (padding, border, border-radius)
- [ ] Есть стиль `:focus` (не только дефолтный outline)
- [ ] `type="email"` и `required` на обязательных полях
- [ ] Кнопка отправки визуально выделена

### Анимации

- [ ] Минимум **2 анимации** на странице
- [ ] Хотя бы одна через `transition` (hover)
- [ ] Анимации плавные, не раздражают (150–400 мс для UI)

### Контент и дизайн

- [ ] Нет заглушек «Lorem ipsum» — реальный контент по теме
- [ ] Минимум 4 изображения в проекте
- [ ] CTA-кнопка в hero с понятным текстом
- [ ] Контраст текста достаточный для чтения

### Git и GitHub

- [ ] Репозиторий инициализирован
- [ ] Минимум **5 коммитов** с осмысленными сообщениями
- [ ] Есть `.gitignore`
- [ ] Есть `README.md` с описанием, автором и инструкцией
- [ ] Код запушен на GitHub (`git push`)
- [ ] Ссылка на репозиторий работает

## Бонус (не влияет на зачёт, но усиливает портфолио)

- [ ] **GitHub Pages** — сайт доступен по ссылке `username.github.io/repo`
- [ ] **Favicon** — иконка вкладки `<link rel="icon" href="...">`
- [ ] **Open Graph** — meta-теги для превью в соцсетях
- [ ] **`prefers-reduced-motion`** — отключение анимаций для доступности
- [ ] **Тёмная тема** через `prefers-color-scheme: dark`

---

## Частые причины несдачи — проверь

- [ ] Проект не на GitHub или ссылка ведёт на пустой репозиторий
- [ ] Только один коммит «initial» без истории работы
- [ ] Нет адаптива — сайт «ломается» на телефоне
- [ ] Flex/Grid не использованы — всё на `float` или без layout
- [ ] Скопирован готовый шаблон без понимания кода
- [ ] Битые пути к изображениям (`src` указывает не туда)
